## 1. 狂野魔法 (Wild Magic) — 《PHB》

### 1 級：狂野魔法 (Wild Magic)

你的天生魔法來自於潛伏於創造秩序之下的狂野混沌之力。你也許曾暴露於某種形式的原初魔力之下，也許穿越了一扇位面傳送門到混沌海、元素位面、或者神秘的遙遠國度。也許你曾被一個強大的精類生物祝福、或被一名惡魔所標記。又或者你的魔法僅僅是你誕生時僥倖獲得，並沒有顯著的原因或理由。無論其來源為何，這道混亂魔力在你體內翻湧著，等待著被以任何方式釋放出來。

#### 狂野魔法浪湧 (Wild Magic Surge)

*1級狂野魔法特性*

你的施法可以釋放出未經馴服的魔法浪湧。緊接在你施放一個1環或更高環的術士法術，DM可以要求你骰一顆d20。若你骰出了1，則擲骰使用狂野魔法浪湧表以創造出一個隨機的魔法效果。一道狂野魔法浪湧在每回合可以發生一次。

若狂野魔法效果為一個法術，則它太過狂野以至於它無法被超魔法影響。若它原本需要專注，則它在這個情況下也不需要專注；該法術將持續到它的完整持續時間。

#### 混亂之潮 (Tides of Chaos)

*1級狂野魔法特性*

你可以操作機率和混亂之力以在一次攻擊檢定、能力檢定、或豁免檢定中獲得優勢。一旦你這麼做，你必須在完成一次長休後才能再使用此能力。

在你重新獲得使用混亂之潮的能力之前，DM可以緊接你施放一個1環或更高環的術士法術後要求你擲骰使用狂野魔法浪湧表。接著你恢復使用混亂之潮的能力。


### 6 級：竄改運氣 (Bend Luck)

*6級狂野魔法特性*

你擁有透過你狂野魔法來扭曲命運的能力。當另一個你所能看見的生物進行一次攻擊檢定、能力檢定、或豁免檢定時，你可以使用你的反應並消耗2點術法點，骰1d4並將擲骰結果作為加值或減值（由你決定）加入該生物的檢定結果。你可以在該生物擲骰後，但在任何該檢定的效果生效之前這麼做。


### 14 級：控制混沌 (Controlled Chaos)

*14級狂野魔法特性*

你獲得了對於你狂野魔法浪湧的些微控制。每當你擲骰使用狂野魔法浪湧表時，你可以重骰二次並使用其中一個擲骰結果。


### 18 級：法術轟擊 (Spell Bombardment)

*18級狂野魔法特性*

你法術的傷害效能量明顯加劇。當你會一個法術擲骰決定傷害，且其中任何一顆骰子骰出了最大的骰面，則從這些骰子中選擇一顆，重骰它並將其擲骰結果加到傷害中。你在每個回合只能使用此能力一次。

## 2. 龍族血脈 (Draconic Bloodline) — 《PHB》

### 1 級：龍族血脈 (Draconic Bloodline)

你的天生魔法來自於與你或你祖先那與龍族魔法交纏的血脈。大多數情況下，這種起源的術士可以追溯其血統到久遠以前與龍族交易、或有著龍族雙親的強大術士。某些這類血脈在世界上相當知名，但絕大部分都不為人知。任何術士都可能因為契約或其他因素，而成為一條嶄新血脈的開端。

#### 龍族血統 (Dragon Ancestor)

*1級龍族血脈特性*

你選擇一個龍種作為你的血統。各龍種對應的傷害型別將會在你往後獲得的能力中被使用。

**龍族血統**

| 龍種 | 傷害型別 |
| :--- | :--- |
| 黑龍 | 強酸 |
| 藍龍 | 閃電 |
| 黃銅龍 | 火焰 |
| 青銅龍 | 閃電 |
| 赤銅龍 | 強酸 |
| 金龍 | 火焰 |
| 綠龍 | 毒素 |
| 紅龍 | 火焰 |
| 銀龍 | 冷凍 |
| 白龍 | 冷凍 |

你能夠說、讀、寫龍語。此外，每當你在與龍族互動時進行魅力檢定，若你的熟練加值能適用於該檢定，你的熟練加值變為二倍。

#### 龍族韌性 (Draconic Resilience)

*1級龍族血脈特性*

因為魔法在你體內流動，你龍族血統的物理特徵開始浮現。你的生命值最大值增加1點，且每當你在本職業提升等級時都會再增加1點。

此外，你一部份的肌膚將會被輕薄、龍族般的光滑鱗片給覆蓋。當你未穿戴護甲時，你的AC等於13 + 你的敏捷調整值。


### 6 級：元素親和 (Elemental Affinity)

*6級龍族血脈特性*

當你施放一個會造成與你龍族血統對應傷害型別相同的傷害的法術時，你可以將你的魅力調整值加入該法術的其中一個傷害骰中。在此同時，你可以消耗1點術法點以獲得對該傷害型別的抗性長達1小時。


### 14 級：龍之翼 (Dragon Wings)

*14級龍族血脈特性*

你獲得從你背後長出一對龍翼的能力，獲得等同於你當下速度的飛行速度。你可以在你的回合以一個附贈動作創造這對龍翼。它們會持續直到你在你的回合以一個附贈動作解消它們。

你無法在你穿戴護甲時操作這對龍翼，除非該護甲是為了容納它們而被打造。此外，未被設計於容納你龍翼的服裝將在你操作龍翼的時候被破壞。


### 18 級：真龍威儀 (Draconic Presence)

*18級龍族血脈特性*

你可以引導來自你龍族血統的駭人威儀，使你周遭的人們因而被震撼或恐懼。以一個動作，你可以消耗5點術法點以汲取這種力量，並散發出一道距離60尺範圍，令人敬畏或恐懼的靈光（由你選擇）。持續1分鐘或直到你失去你的專注（如同你施放一個專注法術），每個在這道靈光中開始它回合的敵意生物必須成功透過一次感知豁免，否則在這道靈光結束前被魅惑（若你選擇敬畏效果）或恐懼（若你選擇恐懼效果）。一個成功透過此豁免檢定的生物將在接下來的24小時內免疫你的靈光。

## 3. 幽影魔法 (Shadow Magic) — 《XGE》

### 1 級：幽影魔法 (Shadow Magic)

身為影之造物，你的天生魔法來自墮影冥界本身。或許你能追溯你的家系到一個來自該處的存在，又或者你曾暴露於墮影冥界的可怕能量之下並被其轉化。

幽影魔法的力量在你的身體表徵上蒙上了一層怪異的帷幕。維持著你的生命火花因壓抑而模糊，彷彿它在與深入你靈魂的黑暗能量對抗而掙扎生存。根據你的選擇，你可以從幽影術士怪異特徵表中為你的角色挑選或擲骰決定一個怪異特徵。

**幽影術士怪異特徵**

| d6 | 怪異特徵 |
| :--- | :--- |
| 1 | 你摸起來永遠如冰般寒冷。 |
| 2 | 當你熟睡時，你像是沒有在呼吸（但你仍需要呼吸以維生）。 |
| 3 | 你鮮少流血，即使受到重傷也一樣。 |
| 4 | 你的心跳每一分鐘才脈動一下。這件事有時候也會讓你驚訝。 |
| 5 | 你難以記住活著的生物和屍體應該被差別待遇。 |
| 6 | 你上週，眨眼，只眨了一次。 |

#### 幽暗之瞳 (Eyes of the Dark)

*1級幽影魔法特性*

你具有120尺範圍的黑暗視覺。

當你在本職業升至3級時，你習得《黑暗術》法術，且它不會計入你的已知術士法術數量中。此外，你可以藉由消耗2點術法點或一個法術位來施放它。若你透過術法點施放它，你可以看透由此法術創造出來的黑暗。

#### 終焉之力 (Strength of the Grave)

*1級幽影魔法特性*

你處於生與死之間模糊狀態的存在使你難以被擊敗。當傷害將你的生命值歸零時，你可以進行一次魅力豁免（DC 5 + 所受到的傷害）。若豁免成功，你改為將你的生命值減少至1。若你是因為光耀傷害或暴擊而導致生命值歸零，則你不能使用此能力。

在該豁免檢定成功後，你直到完成一次長休之前都不能再使用此能力。


### 6 級：凶兆獵犬 (Hound of Ill Omen)

*6級幽影魔法特性*

你獲得呼喚出一個咆嘯著的黑暗生物以侵擾你敵人的能力。以一個附贈動作，你可以消耗3點術法點以用魔法召喚出一個凶兆獵犬，並指定一個距離你120尺內且你所能看見的生物作為目標。這個獵犬使用《恐狼》的資料（參見《怪物圖鑑》或《玩家手冊》的附錄C），但有以下的改變：

- 獵犬的體型為中型，而非大型；且它被視作怪獸，而非野獸。
- 它在出現時擁有等同於你術士等級一半的臨時生命值。
- 它可以如同穿過困難地形一樣移動穿過其他生物和物體。若獵犬在一個物體內結束它的回合，獵犬將受到5點力場傷害。
- 在它的回合開始時，獵犬將自動知曉它目標的所在位置。若該目標在躲藏中，則它對獵犬而言不再視為躲藏中。

### 6 級：心靈防禦 (Psychic Defenses)

*6級畸變心智特性*

6級起，你對心靈傷害獲得抗力。此外，你在對抗魅惑或恐懼的豁免檢定上獲得優勢。


### 14 級：血肉啟示 (Revelation in Flesh)

*14級畸變心智特性*

14級起，你能夠釋放出潛藏在你內部扭曲的真實形態。以一個附贈動作，你使用至少1術法點以魔法性地轉變形態，持續10分鐘。你每因此使用了1術法點，你便可以在轉變形態期間選擇並獲得以下一種增益：

- 你能看見60尺內的隱形生物，前提是其對你不為全遮蔽。
- 你獲得等同於你行走速度的飛行速度，並能停留在空中。當你飛行時，你的皮膚表面流出發光的粘液或是散發出超凡脫俗的光芒。
- 你獲得等同於你兩倍行走速度的游泳速度，且你能在水下呼吸。此外，腮從你的脖子上長出來，或從耳後呈扇狀翻出，你的手指變成蹼趾，或有捲曲的細毛從你的衣服底下翻騰而出。
- 你的身體和你攜帶的裝備都變得柔韌粘滑。你能夠輕鬆穿過最窄1寸寬的狹窄空間而不用擠進去，且你可以消耗5尺移動速度以逃離非魔法的束縛或被擒。


### 18 級：扭曲爆裂 (Warping Implosion)

*18級畸變心智特性*

18級起，你能夠解放你異質的力量，從而製造扭曲空間的異常現象。以一個動作，你可以傳送到120尺內你可見的一個未被佔據的位置，然後你消失位置30尺內的生物必須進行一次力量豁免，失敗受3d10力場傷害並被立即拉向你原本的位置或最近的一個未被佔據的位置，成功半傷且不受拉扯。

一旦你使用了此能力，你在完成一次長休息之前必須消耗5術法點以再次使用此能力。
