## 1. 戰地匠師 (Battle Smith) — 《TCE》

### 3 級：戰地匠師 (Battle Smith)

軍隊需要保護，但當防衛戰失敗時，需要有人來進行重整。身為守護者和醫生的結合，戰地匠師是進行防衛，以及重整工事與人員的專家。戰地匠師大多都攜帶一個由自己製造的防衛性隨從——鋼鐵守衛來輔助自己。無數士兵都曾講述過關於瀕臨死亡的自己被一名戰地匠師，以及他的鋼鐵守衛所拯救的故事。

戰地匠師在卡尼斯家族製造戰鬥構裝體和最初的戰俑時扮演了關鍵的角色。在終末戰爭過後，這些奇械師致力於救助在恐怖的戰爭中受傷的人。

#### 本職工具 (Tool Proficiency)

*3級戰地匠師特性*

你獲得《鐵匠工具》的熟練。如果你已經擁有此熟練，作為代替，你能獲得另一種《工匠工具》的熟練。

#### 戰地匠師法術 (Battle Smith Spells)

*3級戰地匠師特性*

只要你達到相應的職業等級，戰地匠師法術表格中的法術總是被視為已準備。這些法術對你來說是奇械師法術，且不會計入你可以準備法術的總數。

**戰地匠師法術**

| 奇械師等級 | 法術 |
| :--- | :--- |
| 3rd | 《英雄氣概》, 《護盾術》 |
| 5th | 《烙印斬》, 《守護聯結》 |
| 9th | 《活力靈光》, 《召喚箭幕》 |
| 13th | 《淨化靈光》, 《火焰護盾》 |
| 17th | 《放逐斬》, 《群體治療傷勢》 |

#### 戰鬥準備 (Battle Ready)

*3級戰地匠師特性*

你的戰鬥訓練和魔法實驗為你帶來了兩種好處：

- 你獲得軍用武器的熟練。
- 當你以魔法武器攻擊時，你可以在攻擊和傷害檢定使用智力調整值，以代替力量或敏捷。

#### 鋼鐵守衛 (Steel Defender)

*3級戰地匠師特性*

你閒暇的工匠時間讓你創造出可靠的隨從，一個《steel defender》。它對你和你的同伴友好，並且服從你的命令。鋼鐵守衛的遊戲資料見下，它的資料中某幾項會適用你的熟練加值。該生物的外觀，兩足步行還是四足步行皆由你決定；你的決定對遊戲資料沒有影響。

在戰鬥中，鋼鐵守衛使用你的先攻，並且在你的回合後立即行動。它能自由移動和執行反應，但除非你以一個附贈動作命令它進行資料中列出的動作或其他動作，否則它在回合中只能進行閃避動作。如果你無力，鋼鐵守衛可以進行任何動作，而不僅僅是閃避。

如果你對鋼鐵守衛施放《修復術》，它將恢復2d6生命值。如果它在最近一小時內死亡，你能夠以一個動作使用《鐵匠工具》花費一個至少1環的法術位來在距離你5尺的空格內復活它。鋼鐵守衛會在1分鐘後復活，在復活時會回滿生命值。

當你在手頭有《鐵匠工具》的情況下完成一次長休時，你可以創造一個新的鋼鐵守衛。如果你已經透過此特性擁有一個鋼鐵守衛，則上一個會立即消失。如果你死亡，鋼鐵守衛會隨之損毀。


### 5 級：額外攻擊 (Extra Attack)

*5級戰地匠師特性*

每當你在自己回合執行攻擊動作時，你可以發動兩次攻擊，而非一次。


### 9 級：奧能震盪 (Arcane Jolt)

*9級戰地匠師特性*

你學會了新的方法來引導奧術能量進行傷害或治療。當你使用魔法武器或指揮鋼鐵守衛命中目標時，你可以將奧術能量引導至攻擊中，以獲得以下一種效應：

- 目標受到額外的2d6力場傷害。
- 選擇距離目標30尺以內的一個可見生物或物體。治癒能量湧進選擇的物件，為其恢復2d6生命值。

你可以引導奧術能量的次數等同於你的智力調整值（至少1次），但每回合只能這麼做一次。在你完成長休時，恢復所有可用次數。


### 15 級：改良守衛 (Improved Defender)

*15級戰地匠師特性*

你的奧能震盪和鋼鐵守衛變得更強：

- 奧能震盪的額外傷害和生命恢復變為4d6。
- 你的鋼鐵守衛的AC獲得+2加值。
- 當你的鋼鐵守衛使用偏轉攻擊時，攻擊者受到1d4 + 你的智力調整值的力場傷害。

## 2. 鍊金師 (Alchemist) — 《TCE》

### 3 級：鍊金師 (Alchemist)

鍊金師是將奇異的原料混合在一起以產生種種新物質的專家，鍊金師的創造物能用來延續生命，也能用來奪走生命。鍊金術是最古老的奇械師技藝，它的多功能性在戰爭與和平時都長期受到重視。

#### 本職工具 (Tool Proficiency)

*3級鍊金師特性*

你獲得《鍊金工具》的熟練。如果你已經擁有此熟練項，作為代替，你能獲得另一種《工匠工具》的熟練。

#### 鍊金師法術 (Alchemist Spells)

*3級鍊金師特性*

只要你達到相應的職業等級，鍊金師法術表格中的法術總是被視為已準備。這些法術對你來說是奇械師法術，且不會計入你可以準備法術的總數。

**鍊金師法術**

| 奇械師等級 | 法術 |
| :--- | :--- |
| 3rd | 《治癒真言》, 《致病射線》 |
| 5th | 《熾焰法球》, 《馬友夫強酸箭》 |
| 9th | 《氣化形體》, 《群體治癒真言》 |
| 13th | 《枯萎術》, 《防死護咒》 |
| 17th | 《死雲術》, 《喚醒死者》 |

#### 實驗性靈藥 (Experimental Elixir)

*3級鍊金師特性*

每當你完成一次長休，你能在一個你接觸的空瓶中魔法性的製造出一劑*實驗性靈藥*。當某人飲用靈藥時，透過實驗性靈藥表來擲骰決定靈藥的效果。以一個動作，一個生物能自己飲用靈藥，或是將靈藥給一個無力生物飲用。

你需要擁有《鍊金工具》才能製造*實驗性靈藥*，你透過此特徵創造的所有靈藥會一直存在到被飲用，或是你下一次長休結束時。

當你達到某些特定等級時，將能夠在長休結束時製造更多靈藥：6級時2劑，15級時3劑。每劑靈藥都需要擲骰決定效果。每一劑靈藥都需要用獨立的燒瓶盛放。

你能透過消耗一枚1環或更高環的法術位來製造額外的*實驗性靈藥*。要這麼做的話，你需要以一個動作接觸一個空燒瓶來製造靈藥，然後從"實驗性靈藥表"中選擇這劑靈藥的效果。

**實驗性靈藥**

| d6 | 效果 |
| :--- | :--- |
| 1 | **治療**。飲用者恢復 2d4 + 你智力調整值的生命值 |
| 2 | **疾速**。飲用者在1小時內速度增加10尺。 |
| 3 | **韌性**。飲用者在10分鐘內AC獲得+1加值。 |
| 4 | **勇氣**。飲用者在1分鐘內，能夠在每個攻擊檢定和豁免檢定中增加一個d4。 |
| 5 | **飛行**。飲用者在10分鐘內獲得10尺飛行速度。 |
| 6 | **變形**。飲用者的身體產生如同《變造自身》法術的變化。具體怎樣變化由飲用者決定，持續時間10分鐘。 |


### 5 級：鍊金術掌握 (Alchemical Savant)

*5級鍊金師特性*

你對魔法化學物質的掌握變得非常熟練，這將提高你透過鍊金物質造成的治療和傷害效果。當你使用《鍊金工具》作為法器施法時，你在法術的一次擲骰中獲得加值。該擲骰必須恢復生命值，或是造成強酸、火焰、黯蝕或毒素傷害，獲得的加值等於你的智力調整值（最低+1）。


### 9 級：復原藥劑 (Restorative Reagents)

*9級鍊金師特性*

你可以在你的一些作品中加入復原藥劑：

- 每當一個生物飲用一劑你製造的*實驗性靈藥*時，該生物獲得2d6 + 你智力調整值的臨時生命值（至少1點臨時生命值）。
- 此外，只要你使用《鍊金工具》作為法器，就可以在不花費法術位的情況下施展《次級復原術》。你能夠這麼做的次數等於你的智力調整值（最少1次），在你完成一次長休後，將恢復所有可用次數。


### 15 級：化學專家 (Chemical Mastery)

*15級鍊金師特性*

你已經接觸了太多的化學物質，並解開了它們的秘密，它們對你的危害很小，你可以使用它們來迅速治癒某些疾病：

- 你獲得了對強酸傷害和毒素傷害的抗性，同時對中毒狀態免疫。
- 只要你使用《鍊金工具》作為法器，就能夠在不消費法術位和材料成分的情況下施展《高等復原術》和《治癒術》。一旦你透過此特性施法，必須完成一次長休才能再次使用此特性。

## 3. 裝甲師 (Armorer) — 《TCE》

### 3 級：裝甲師 (Armorer)

對於裝甲師專業的奇械師來說，裝甲就像是第二層皮膚。這一裝甲能夠增強奇械師的魔法，釋放強力的攻擊，產生絕佳的防護。這些奇械師與他們的裝甲之間有著強力的紐帶，在他們經過實驗並改進裝甲的魔法效能後，甚至能夠合二為一。

#### 本職工具 (Tools of the Trade)

*3級裝甲師特性*

你獲得重甲的熟練。你同時獲得《鐵匠工具》的熟練，如果你已經熟練於此工具，作為代替，你能獲得另一種《工匠工具》的熟練。

#### 裝甲師法術 (Armorer Spells)

*3級裝甲師特性*

只要你達到相應的職業等級，裝甲師法術表格中的法術總是被視為已準備。這些法術對你來說是奇械師法術，且不會計入你可以準備法術的總數。

**裝甲師法術**

| 奇械師等級 | 法術 |
| :--- | :--- |
| 3rd | 《魔法飛彈》, 《雷鳴波》 |
| 5th | 《鏡影術》, 《粉碎音波》 |
| 9th | 《催眠圖紋》, 《閃電束》 |
| 13th | 《火焰護盾》, 《高等隱形術》 |
| 17th | 《穿牆術》, 《力牆術》 |

#### 奧能裝甲 (Arcane Armor)

*3級裝甲師特性*

你對冶金的鑽研讓你的盔甲成為了實現你奇械師魔法的渠道。只要你手持《鐵匠工具》，就能以一個動作將你正穿著的一套重甲變成奧能裝甲。

在穿著奧能裝甲時，你獲得以下好處：

- 如果你的盔甲通常對穿戴者的力量有要求，奧能裝甲能讓你無視它。
- 你能夠將奧能裝甲作為你奇械師法術的法器。
- 穿在你身上的奧能裝甲除非你自願，否則無法移除。同時，奧能裝甲能夠擴充套件到覆蓋你的整個身體，並替換你所有缺失的肢體，替換肢體的部分擁有和正常肢體一樣的功能。
- 你能以一個動作穿著或脫下裝甲。護甲會一直保持奧能裝甲的功能，直到你穿著另一套盔甲或你死亡。

#### 裝甲型號 (Armor Model)

*3級裝甲師特性*

你能夠定製你的奧能裝甲。當你這麼做時，能夠從以下兩種型號中選擇其一：守護者 或 滲透者。你選擇的型號會在你穿著時提供特殊的好處。

每種型號都包括一種特殊武器。當你使用該武器攻擊時，你可以使用你的智力調整值，而不是力量或敏捷，來進行攻擊和傷害檢定。

只要你手上有《鐵匠工具》，就可以在完成一次短休或長休後更換你的裝甲型號。

###### 守護者

你將裝甲設計為適合衝鋒陷陣。它擁有下列特性：

- **雷霆戰拳。**：每一隻裝甲附帶的手套在沒有持握任何物品時皆可被視為一件簡單近戰武器，命中後會造成1d8 雷鳴傷害。被戰拳擊中的生物，會被裝甲釋放的魔法性干擾脈衝影響，使其對除你之外的目標攻擊時有劣勢，直到你的下個回合開始。
- **防護場。**：在每個你的回合，你能以一個附贈動作獲得等於你奇械師職業等級的臨時生命值，這會取代你現有的任何臨時生命值。如果你脫下裝甲，你會失去這些臨時生命值。你能執行此附贈動作一共等同於你熟練加值的次數，在完成一次長休後將恢復所有花費的使用次數。

###### 滲透者

你出於某些特殊需要對你的裝甲進行了定製。它擁有下列特性：

- **閃電發射器。**：你在胸部或覆蓋裝甲的拳頭（根據你的選擇）上安裝了一個寶石狀的節點。它被視為一件簡單遠端武器，它擁有90尺的常規射程和300尺的最大射程，在命中後會造成1d6閃電傷害。每個你的回合一次，你在透過閃電發射器命中一個生物時，能夠額外造成1d6 閃電傷害。
- **動力步伐。**：你的步行速度增加5尺。
- **減震場。**：你在敏捷（隱匿）檢定中具有優勢。如果你的盔甲原本會讓你在此檢定上具有劣勢，優勢和劣勢將會正常抵消。


### 5 級：額外攻擊 (Extra Attack)

*5級裝甲師特性*

每當你在自己回合執行攻擊動作時，你可以發動兩次攻擊，而非一次。


### 9 級：裝甲改造 (Armor Modifications)

*9級裝甲師特性*

你習得了如何透過奇械師注法對你的奧能裝甲進行特殊改造。奧能裝甲現在你進行注法時，能夠被視為下列獨立物品：盔甲（胸甲）、靴子、護腕和武器。每件物品都能進行一次注法，此外，你的注法物品的上限增加2，但增加的部分只能用於為奧能裝甲的一部分注法。


### 15 級：完美裝甲 (Perfected Armor)

*15級裝甲師特性*

你的奧能裝甲根據其型號獲得下列額外好處。

#### 守護者

對你奧能裝甲能量系統的改進使你能夠釋放強大的拉力。當你可見的一個體型為巨型或更小的生物在距離你30尺內的地方結束其回合時，你能以一個反應迫使該生物對你的法術豁免DC進行一個力量豁免檢定，失敗將被拉向你最多30尺。如果你將目標拉到距離你5尺的地方，作為此反應的一部分，你能對該生物進行一次近戰武器攻擊。

你能夠執行此反應的次數等於你的熟練加值，在完成一次長休後將恢復所有可用次數。

#### 滲透者

任何被你閃電發射器造成閃電傷害的生物將在你的下個回合到來前發光。發光的生物會放出5尺半徑的微光光照，當它試圖攻擊你時，光芒會突然增強，使其在針對你的攻擊檢定中具有劣勢。另外，下次針對發光生物的攻擊檢定具有優勢。如果那次攻擊命中，將額外造成1d6閃電傷害。

## 4. 魔炮師 (Artillerist) — 《TCE》

### 3 級：魔炮師 (Artillerist)

魔炮師是在戰場上投射能量、炮彈和爆炸物的專家。這種破壞力在終末戰爭中受到所有軍隊的重視。而現在，戰爭已經結束，這一專業的部分人員開始試圖運用自己的力量來消滅科瓦雷中的戰爭火種，從而建立一個更加和平的世界。

看上去不像，但事實上是卡尼斯家族戰俑計劃關鍵人物的侏儒奇械師Vi一直都大力宣揚要做正確的事："現在這個時代，應該致力於修復，而不是把一切都轟下地獄。"

#### 本職工具 (Tool Proficiency)

*3級魔炮師特性*

你獲得《木雕工具》的熟練。如果你已經擁有此熟練，作為代替，你能獲得另一種《工匠工具》的熟練。

#### 魔炮師法術 (Artillerist Spells)

*3級魔炮師特性*

只要你達到相應的職業等級，魔炮師法術表格中的法術總是被視為已準備。這些法術對你來說是奇械師法術，且不會計入你可以準備法術的總數。

**魔炮師法術**

| 奇械師等級 | 法術 |
| :--- | :--- |
| 3rd | 《護盾術》, 《雷鳴波》 |
| 5th | 《灼熱射線》, 《粉碎音波》 |
| 9th | 《火球術》, 《風牆術》 |
| 13th | 《冰風暴》, 《火牆術》 |
| 17th | 《寒冰錐》, 《力牆術》 |

#### 魔能炮臺 (Eldritch Cannon)

*3級魔炮師特性*

你習得了如何製造一架魔法炮臺。只要你手持《木雕工具》或《鐵匠工具》，你能以一個動作在距離你5尺且沒被佔據的水平空格內魔法性地召喚出一架小型或微型炮臺。小型魔能炮臺會佔據它所在的方格，而微型炮臺能直接拿在手裡。

你能夠免費召喚一次炮臺，若如此做，你必須完成一次長休才能再次進行。但是你也可以透過消耗一枚法術位來製造炮臺。你同時只能擁有一架炮臺，並且不能製造第二架炮臺。

無論炮臺有多大，它都是魔法物件。它的AC是18，生命值是你奇械師等級的5倍。它對毒素傷害和心靈傷害免疫。如果它被迫進行能力檢定或豁免檢定，則將其所有屬性都視為10(+0)。如果對炮臺施展《修復術》，它將恢復2d6生命值。炮臺在生命值降低到0或者1小時後消失。你能以一個動作來提前讓其消失。

當你製造炮臺時，你可以決定它的外觀以及是否有腿，並且需要從魔能炮臺列表中選擇它的型別。在你的每個回合中，只要你離炮臺不到60尺，就能以一個附贈動作來啟用炮臺。作為同一動作的一部分，你可以引導有腿的炮臺步行或攀爬到15尺內的一個未佔用的空間中。

**魔能炮臺**

| 炮臺 | 啟用 |
| :--- | :--- |
| **投火器** Flamethrower | 炮臺在你指定的一個15尺錐形範圍內發射火焰。該區域內的每個生物必須對你的法術豁免DC做一次敏捷豁免檢定，如果豁免失敗則受到2d8火焰傷害，成功的豁免檢定將使傷害減半。火焰會點燃該地區內任何未被穿戴或攜帶的易燃物品。 |
| **力場弩炮** Force Ballista | 對一個距離炮臺120尺以內的生物或物體進行遠端法術攻擊。擊中時，目標受到2d8力場傷害，如果目標是一個生物，它將向遠離炮臺的方向推開5尺。 |
| **保護者** Protector | 炮臺釋放出一股正能量，給予它自己和10尺距離內每個你選擇的生物1d8 + 你智力調整值的臨時生命值（最低+1）。 |


### 5 級：奧法火器 (Arcane Firearm)

*5級魔炮師特性*

你知道如何把魔杖、法杖或權杖變成一件奧法火器，一個傳送你的毀滅性法術的管道。當你完成一次長休後，你可以用《木雕工具》在一根魔杖、法杖或權杖上刻印一個特殊印記，從而把它變成你的奧法火器。印記會一直存在，除非你之後在另一件物品上刻上這種印記，這樣的話，之前物體上印記就會消失。

你可以將你的奧法火器作為你奇械師法術的法器。當你透過奧法火器施放一個奇械師法術時，擲一個d8，你在法術的一次傷害骰中獲得與擲骰結果相同的加值。


### 9 級：高爆炮臺 (Explosive Cannon)

*9級魔炮師特性*

你製造的每一門魔能炮臺都將擁有更大的破壞力：

- 所有炮臺的傷害增加1d8。
- 如果你距離炮臺不到60尺，你能以一個動作命令你的炮臺自爆。這麼做會摧毀炮臺，並迫使每一個離它20尺以內的生物對你的法術豁免DC進行一次敏捷豁免檢定，若豁免失敗，將受到3d8力場傷害，豁免成功則傷害減半。


### 15 級：堅固要塞 (Fortified Position)

*15級魔炮師特性*

你成為了用魔能炮臺構築陣地的大師：

- 由於你用魔能炮臺特性創造的炮臺所發出的閃光魔法保護場，你和你的盟友在距離炮臺10尺以內時具有半掩蔽。
- 你現在同時擁有二架炮臺，你能以一個動作同時製造兩架炮臺（但使用法術位製造時，每個炮臺都要一個法術位）。此外，你能夠以一個附贈動作來同時啟用兩架炮臺。這兩架炮臺可以是不同的型別。你在擁有兩架炮臺時，不能製造第三架炮臺。
