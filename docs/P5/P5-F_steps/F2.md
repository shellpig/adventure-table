# F2 — Tactical Stage UI（frontend）

## Scope

依 [實作紀錄](../P5-F實作紀錄.md) 技術決策 5～8：

- 既有 Session Main Stage 在 `mode=tactical` 切 Tactical Stage：Combat Header／Round／Current Turn、Battle Map、initiative context、Token selection、movement plan／preview、range／target feedback、AoE template preview、compact combat log、OA／reaction 與 pending movement（resume／cancel）。
- Camera：bounded zoom、pan、wheel／pinch、drag empty space、middle mouse、Fit Map、optional Center Party；純 client state。
- Player drag 只改 draft plan；Confirm 才寫 canonical。
- DM toolbar：Select、Wall、Door、Terrain、Token、Draw、Erase、Undo、Fit Map；setup／reposition 與 gameplay movement 視覺與 command 分離；hidden wall／door 在 DM 視圖可辨識。
- Player 只 render server projection，不在前端藏 hidden 資料。
- 所有新 copy `zh-TW`＋`en`（`*Copy.ts` parity、`hardcodedUiCopy`）。
- Playwright spec `apps/web/e2e/p5f-tactical-combat.spec.ts` 覆蓋 F.1、F.2。
