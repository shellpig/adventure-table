# F2 — Battle map 編輯器與 Tactical Stage 骨架（frontend）

## Scope

依 [實作紀錄](../P5-F實作紀錄.md) 技術決策 5～8：

- API client：battle maps（list／create／get／patch／replace objects；`apps/server/app/api/rooms/battle_maps.py`）、`POST .../combat/tactical-start`、`GET .../combat/board`、`GET .../combat/board/image`、`PUT .../board/positions/{entry_id}`、`PATCH .../board/doors/{door_id}`。型別對照 server model，不自造欄位。
- DM battle map 編輯器：建立空白格線地圖（及既有 image map 顯示）、toolbar 至少 Select、Wall、Door、Terrain、Token、Draw、Erase、Undo、Fit Map；編輯是 client working state，存檔走 replace objects（expected revision）；wall／door 可設 hidden，DM 視圖可辨識 hidden wall／door（F1 的 wall `visibility`）。
- Tactical start：DM 選 map 開 Tactical Combat；placement（DM 放 Token）。
- 既有 Session Main Stage 在 `mode=tactical` 切 Tactical Stage：Combat Header／Round／Current Turn、Battle Map render（grid、walls、doors、terrain、tokens）、initiative context、Token selection、compact combat log（沿用既有 combat log）。
- Camera：bounded zoom、pan、wheel／pinch、drag empty space、middle mouse、Fit Map、optional Center Party；純 client state，不存 localStorage、不打 server API。
- Player 只 render server projection；不在前端藏 hidden 資料。
- 所有新 copy `zh-TW`＋`en`（`*Copy.ts` parity、`src/i18n/hardcodedUiCopy.test.ts`）。
