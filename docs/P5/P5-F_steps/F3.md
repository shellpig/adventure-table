# F3 — Tactical gameplay UI 與 Playwright spec（frontend）

## Scope

依 [實作紀錄](../P5-F實作紀錄.md) 技術決策 7、8，接在 F2 的 Tactical Stage 上：

- Player drag 自己可控 Token 只改 client draft path，呼叫 movement preview 顯示 used／remaining 與不合法原因；Confirm 才呼叫 confirm。不能拖別人的 Token。
- Pending movement（P5-E paused）：顯示暫停狀態、resume（mover 或 DM）、DM cancel-pending。
- Range／target feedback：選攻擊或法術目標時呼叫 `board/target-check`，顯示 in range／long range／blocked／out of range。
- AoE template preview：依 P5-D preview 回傳 cells 畫範圍，模板輪廓以 `apps/server/tests/fixtures/p5d_aoe_golden.json` 對齊；接既有 propose／resolve 流程。
- OA／reaction：自動 OA 開 window 時沿用既有 reaction UI 呈現並可回應。
- DM reposition：與 gameplay movement 不同模式與 command。
- 所有新 copy `zh-TW`＋`en`。
- Playwright spec `apps/web/e2e/p5f-tactical-combat.spec.ts` 覆蓋 F.1 journey 與 F.2 camera。

規格 §10.1、§10.3、§10.4；設計 §10.1、§10.2、§10.5；測試 F.1、F.2、F.7。
