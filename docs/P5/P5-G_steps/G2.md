# G2 — Browser E2E 與 UI 修補（agy）

## Scope

- **G.1 Quick regression**：延伸 `apps/web/e2e/p4e-quick-combat.spec.ts`（或新增 `p5g-quick-regression.spec.ts`），Start Quick → initiative → range 由 DM adjudicate → AoE 由 DM 指定 targets → OA 由 DM trigger → End Combat；斷言全程不出現 Tactical map UI、不打 `/combat/board` 寫入。
- **G.2 Tactical full journey**：新增 `apps/web/e2e/p5g-tactical-full-journey.spec.ts`，補 `p5f-tactical-combat.spec.ts` 未涵蓋的部分：SRD Monster＋Quick Enemy、Large token、normal＋diagonal movement、Difficult Terrain、split movement、ranged normal／long／out 至少兩種、AoE、OA、reaction resume、Shove 或 Grapple、hidden entity、Session End → next Session resume、End Combat。
- spec 揭露的前端 bug 在 `apps/web/src/**` 修正；需要 backend 改動時停下回報。

## 對應契約

規格 §11；測試指南 G.1、G.2、§4。
