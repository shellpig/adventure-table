## Scope

新增 `tests/test_p5g_*.py`，把測試指南 G.3、G.4、G.6 的 backend 面補成可定位的測試，並修正測試揭露的 production bug：

- **G.3 Real PostgreSQL restart**：在 `test_p5e_acceptance.py::test_postgres_restart_recovers_paused_movement_and_resumes_once` 之外，restart（重建 engine／service graph）後還要恢復 active board、positions、round／turn、movement bookkeeping、pending ReactionRequest、pending roll／action、hidden projection、Door／Terrain runtime state；resolve 後只續一次。只以真 PostgreSQL 為證據。
- **G.4 Concurrent stale command**：Human 與 AI 同時 Confirm 同一 subject movement；DM correction（reposition）與 Player 舊 movement 競爭；map runtime revision（door state）變更與舊 AoE confirm 競爭。只允許一個合法 transition，另一方拿穩定 stale／conflict error 且零副作用。
- **G.6 Secrecy matrix**：DM／Human Player／AI Player × hidden token、hidden door、hidden wall、既有 enemy secrets、runtime secret ids、movement interruption error、AoE preview × event／Resume／REST／MCP。DM 必須看得到；Player 路徑含順序、計數側通道不得洩漏。
