# B2 — Hidden interruption、DM reposition、B1 審核修正與測試缺口

## Scope

- **Hidden blocker 正式中斷（B.7）**：Confirm 先以 caller 可見的 board projection 驗 path；可見資料下就非法 → 維持 400 `combat_movement_invalid`、零副作用。可見資料下合法、但 full Server truth 下被 hidden monster／hidden wall／未揭露 hidden door 擋住 → 不移動、不改 `movement_*`，回 200 `ConfirmMovementView` 帶 `outcome="interrupted"`（成功移動為 `outcome="committed"`），同一 transaction append `combat.movement_interrupted`。Player 投影的 payload 只有 `combat_id`、`entry_id`、`reason="path_obstructed"`；DM 投影另含中斷的 step index 與 blocker 類型／id。投影走 `project_combat_event_payload`，hidden monster id 不得出現在 Player 版任何欄位（含 P5-A `_ID_KEYS` 名單外的 key）。同 idempotency key retry 回同一 interrupted 結果、不重複 append。DM caller 看得到全部，不會觸發 interruption。
- **DM Reposition／Correction（B.8）**：`POST .../combat/board/reposition`（DM only；body `entry_id`、`anchor_x`、`anchor_y`、`reason`（必填 1～500 字）、`expected_position_revision`、`idempotency_key`）。以 full truth 做 placement 驗證（bounds、blocked、overlap、跨牆），不走 path、不扣 budget、不改 diagonal parity、不受 turn 限制。同 transaction 更新 position（`revision+1`）與 board `runtime_revision`，append `combat.position_corrected`（acting DM seat、subject、reason）；Player 投影不含 `reason`，hidden monster 的事件 `visibility='dm_only'`。Player／AI Player 呼叫 → 拒絕、零副作用。
- **B1 審核修正**：
  1. `MovementService.confirm` 的 idempotency replay 在 authorization 之前執行，且未核對 replay payload 的 `entry_id`、acting seat（回傳 view 還用 request 的 `entry_id` 覆蓋）。改為先授權，再只在 payload `entry_id` 與 acting seat 都一致時回放；不一致視為 key 衝突 → 409。
  2. `crosses_wall_or_closed_door` 的 diagonal 切角只檢查 anchor 格；多格 footprint 斜走時，footprint 前緣的角格（例：Large 從 (0,0) 到 (1,1) 的 (2,0)、(0,2)）與其邊未檢查。改為對整個 footprint 的 sweep 檢查切角。
- **補齊 B1 測試缺口**（測試指南逐條）：
  - B.1：Move（含 diagonal）→ Attack → Move，diagonal parity 延續不重置。
  - B.2：service 層（不是只測 validator）Closed 與 Locked door 擋住、Open／Broken 放行，door state 由 runtime door 改變。
  - B.4：Bonus Action、Extra Attack 穿插不重置 movement；finalize initiative、End Combat、withdraw、remove 會把四個 `movement_*` 欄位清零（目前只測了 `advance_turn`）。
  - Secrecy：Player Preview 不受 hidden wall 與未揭露 hidden door 影響、回應 JSON 不含其 id／座標；DM Preview 被它們擋住。
  - Actor：非本 Combat participant（另一 Room／Campaign 或未入座者）Preview／Confirm 被拒且零副作用。
