# E1 — 自動 OA 與 spatial reactions

## Scope

依 [實作紀錄](../P5-E實作紀錄.md) 技術決策 1～10，一次交付：

- Reach crossing detector（純函式，放 `app/domain/spatial/`）：輸入 previous／next footprint、reactor footprints 與 reach、movement cause，回傳 deterministic 排序的 eligible reactors。只有 cause = voluntary 才觸發。
- `open_opportunity_attack_window` 放寬：Tactical 且 Server 已確認 geometry 時接受 `dm_adjudicated=False`；Quick 仍拒絕。不新增第二種 window 型別；既有 DM 手動 OA 流程在 Tactical 保留。
- MovementService：confirm 在 trigger boundary 暫停、寫 `pending_movement_state`、開 window；resume／cancel-pending command 與 route；resume revalidation；idempotency 回放。
- `advance_turn` guard（409、零副作用）；`pending_movement_state` 由既有 reset 清空（incoming entry、finalize、End、withdraw／remove），不另加 cleanup UPDATE。
- Migration `0039_p5e_disengaged` 與 Disengage 寫入／reset。
- Shove push 位移、Grapple drag。
- Secrecy：hidden reactor 不自動 OA、只留 DM-only 事件；hidden mover 事件 DM-only；Player 的 paused view／錯誤不含 hidden 資訊。
- 新 error code／event 的 user-visible 文字比照既有 combat error 處理 locale。
