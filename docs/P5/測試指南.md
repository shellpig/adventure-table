## 2. P5 核心風險

P5 最危險的 regression 包括：

- Tactical 另建一套 Attack / Spell / Reaction resolution。
- Quick Combat 開始要求 map / position。
- Combat mode 可中途 Quick ↔ Tactical 切換。
- Player 拖 token 直接改 DB position。
- preview 合法但 Confirm 用另一套 distance 演算法。
- 5/10 diagonal 在 split movement 中錯誤重置。
- Large/Huge footprint 只算 anchor 導致 range / collision 錯。
- Difficult Terrain cost 錯或可穿 Blocked。
- creature-space 穿越規則錯。
- hidden token 透過 pathfinding / error / AoE preview 洩密。
- hidden door 在 Player payload 仍有 hidden metadata。
- Wall 擋 movement 但 direct attack 仍可穿牆。
- Cover 被誤做成未拍板的 automatic LOS system。
- AoE renderer 與 Server affected list 不一致。
- AoE retry 重扣 slot / 重傷害。
- voluntary / forced movement 混在一起造成 Shove 也觸發 OA。
- OA reaction 期間 movement 繼續跑到底。
- reaction 打倒 mover 後剩餘 path 仍執行。
- restart / reconnect 丟失 pending movement / ReactionRequest。
- Map Definition 被 Combat runtime mutation 污染。
- Definition 後續修改讓 active Combat map 漂移。
- DM reposition 被算成正常 movement / 觸發 OA。
- AI MCP 可直接寫 coordinates 繞過 rules。
- P5 multiplayer schema 污染 Standalone。
- camera / zoom 被當成 Campaign canonical state。

P5 minimum gate：

```text
map definition/runtime separation
+ canonical 2D footprint positions
+ placement gate
+ 5/10 shared distance
+ authoritative movement budget/path
+ terrain/collision
+ range/reach/hard blocker
+ deterministic AoE cells/targets
+ automatic voluntary-movement OA
+ durable movement/reaction pause-resume
+ hidden spatial secrecy
+ Quick Combat regression
+ Human/AI service parity
+ PostgreSQL migration/concurrency
+ restart/reconnect
+ standalone independence
+ full browser Tactical journey
+ real ChatGPT Web Tactical journey
```

## P5-A — Battle Map & Spatial Foundation

### A.1 Map Definition

自動測至少：

- 建 Blank Grid。
- 建 image map並保存 grid pixel size / offsets。
- Wall / Door / Terrain / Drawing roundtrip。
- Door 四狀態 roundtrip。
- hidden object audience projection。
- Room A 不能讀／改 Room B map。
- Room-scoped image asset 不可跨 Room 越權引用。

### A.2 Definition vs runtime

Journey：

```text
Map Definition door = closed
→ Start Tactical Combat
→ runtime door = broken
→ assert Definition仍 closed
→ edit Definition
→ assert active Combat runtime不漂移
→ reload/reconnect仍維持該場runtime state
```

### A.3 Footprint / placement

Table-driven：Tiny / Small / Medium = 1x1；Large = 2x2；Huge = 3x3；Gargantuan = 4x4。另測 board edge、blocked terrain overlap、combatant overlap、retry不產生 duplicate position。

### A.4 Tactical start gate

未放完所有 current combatants 不可進 initiative；全部 placed 後可開始；mid-combat entrant 先 placement 再 initiative；Quick Combat 不受此 gate 影響。

### A.5 Secrecy

直接檢查 REST / event / MCP DTO：hidden token id/name/position 不存在於 Player payload；hidden door 不以 `hidden=true` 整筆送 Player；DM payload 有完整資料。

## P5-B — Movement & Path Resolution

### B.1 5/10 diagonal

至少測 orthogonal=5、diagonal sequence=5/10/5/10、Move→Attack→Move parity 不重置、new Turn reset、Dash 增 budget 但不重置 parity。

### B.2 Terrain

同一路徑測 Normal、Difficult double cost、Blocked reject、Wall reject、Closed/Locked Door reject、Open/Broken Door pass。

### B.3 Creature space

至少測 nonhostile 可穿 + difficult cost；hostile 同尺寸不可穿；hostile 尺寸差 >=2 可穿 + difficult cost；不可結束在另一 creature occupied space；multi-cell footprint 驗整個 footprint 而非 anchor。

### B.4 Split movement

```text
Move 10
→ Attack
→ Move 15
→ assert used = 25
→ no reset
```

另測 Bonus Action、Extra Attack 穿插不重置 movement。

### B.5 Preview / Confirm stale state

preview 成功後由另一 actor / DM 修改 Door 或 position，再用舊 preview Confirm；Server 必須重驗並拒絕／要求 replan，不得信 client cached result。

### B.6 Atomicity

非法 path 後 position、movement used、diagonal parity、events 都不得留下半筆。duplicate Confirm 只移動一次。

### B.7 Hidden interruption

DM view 有 hidden creature 在 path；Player preview 不得看到 blocker；Confirm 時 error/event 不曝露 identity / hidden coordinate；最終 interruption/adjudication payload 只含安全資訊。

### B.8 DM reposition

不扣 movement、不改 parity、不觸發 OA（P5-E 接線後 cross-test），audit 有 acting DM + subject + reason。

## P5-C — Range, Reach & Spatial Targeting

### C.1 Shared distance

同一 fixture 對 movement helper、ranged targeting、melee reach、AoE distance primitive 驗證相同兩 footprint 得到一致 distance。

### C.2 Multi-cell range

Large / Huge 對 1x1 target 使用最近 occupied-cell pair；加入 anchor-to-anchor 會算錯的反例。

### C.3 Melee reach

adjacent 5 ft 合法、超 reach 拒絕、explicit reach weapon/action 合法距離、hard wall 中間 direct targeting 拒絕。

### C.4 Ranged band

至少測 normal range、long range → P4 modifier pipeline 收到 long-range disadvantage fact、out of range reject。Quick 同一 attack 仍走 DM adjudication，不要求 position。

### C.5 Door / wall / cover

Wall、Closed/Locked Door 擋 direct attack；Open/Broken Door 不擋。Cover 不得被 generic engine 自動加 +2/+5 AC。

### C.6 P4 reuse

測一個 weapon attack：Tactical spatial validate → same P4 formal roll → same P4 damage pipeline → same Character/Monster mutation。不得出現 Tactical-specific RollResult / damage model。

## P5-D — AoE & Tactical Spell Geometry

### D.1 Shape golden fixtures

固定 grid 對 circle、cone、line、square 保存 golden affected cells；特別覆蓋 cell-center boundary cases。前端 renderer fixture 與 Server geometry fixture 必須對齊。

### D.2 Multi-cell targets

大型 creature 任一 occupied cell center 被涵蓋即為 candidate；完全未涵蓋不得加入。

### D.3 Preview / canonical parity

browser/client preview affected cell set 與 Server Confirm result一致；若 board revision 已變更則 Confirm 重算或拒絕 stale preview。

### D.4 Spell integration

```text
choose template
→ preview cells/targets
→ confirm
→ existing RollGroup saves
→ existing damage resolution
```

duplicate confirm 不重建 saves、不重扣 slot、不重傷害。

### D.5 Hidden AoE

Player preview 不能因 template 碰到 hidden token 就顯示該 cell / target identity；DM full view 可看完整 candidate。

### D.6 Obstruction adjudication

選一個需要特殊 wall propagation 判斷的 effect，確認 generic AoE 不假裝完整自動化，可進 DM adjudication / specific resolver，且 final affected list 只 resolve 一次。

## P5-E — Opportunity Attack & Spatial Reactions

### E.1 Basic OA

```text
Mover starts within enemy reach
→ voluntary path exits reach
→ movement pauses
→ ReactionRequest created
→ reactor accepts/declines
→ continue path
```

Reaction 消耗走既有 P4 state。

### E.2 No false OA

forced movement、Shove displacement、teleport、DM reposition 都不得自動 OA。

### E.3 Multiple reactors

同一 exit 同時離開多個 reach：reaction order deterministic；reload後 order不變；duplicate movement command 不建立第二組 ReactionRequest。

### E.4 Reaction changes mover

至少測 OA 打到 0 HP → remaining path 不執行；reaction 造成 speed=0 → stop；reaction 改變 position → old remaining path 重驗；reaction 無影響 → 從 durable path index 續走。

### E.5 Restart / reconnect

pending OA 時 restart：board position、path progress、pending ReactionRequest 都正確恢復；resolve 後只續一次。

### E.6 Grapple / Shove

dragging cost 符合規則；dragged footprint 碰 blocked reject；Shove 5 ft 更新 position；Shove 撞 wall/occupied invalid；Shove 不觸發 OA；cliff/hazard 不自動套 fall damage，留 DM 裁定。

## P5-F — Tactical Combat UI & AI Tool Surface

### F.1 Browser Tactical journey

Playwright 最低：DM Start Tactical → 選 map → placement → initiative → Player drag own token只產生 plan → preview used/remaining → Confirm 後 position 變 → ranged attack range feedback → AoE preview → automatic OA + reaction → DM reposition → hidden token 在 Player DOM / network 不存在。

### F.2 Camera

zoom / pan 不改 Server gameplay state；Player A camera 不影響 Player B；若有 local persistence，refresh 只恢復本 client preference。

### F.3 Authority

Player 只能 move 自己合法 subject；不能 DM reposition、edit wall/door/terrain。Current DM 可 setup/reposition/reveal。DM proxy normal movement 仍耗 subject budget。Revoked AI grant 不能再 movement。

### F.4 MCP protocol

沿 M04 protocol 測 role-scoped catalog、tactical context、movement preview/confirm、targeting、AoE、pending reaction；每次 call 重驗 grant / epoch / OAuth authority；Player context 不含 hidden geometry。

### F.5 Human / AI parity

對同一 fixture，Human movement command 與 AI movement tool 進同一 application service，得到相同 position / movement cost / events。

### F.6 Briefing

自動斷言 Tactical briefing 含 current mode、turn、visible positions、movement remaining、pending movement/reaction、next required action。

## P5-G — Full P5 Integration & Closeout

### G.1 Quick regression

完整 Quick journey 不建立 map：Start Quick → initiative → range由DM adjudicate → AoE由DM指定 targets → OA由DM trigger → End Combat。P5 加入後全程不要求 coordinates / board。

### G.2 Tactical full browser journey

至少包含 SRD Monster + Quick Enemy、map、至少一個 Large token、placement、initiative、normal + diagonal movement、Difficult Terrain、split movement、ranged normal/long/out至少兩種、AoE、OA、reaction resume、Shove或Grapple、hidden entity、Session End → next Session resume、End Combat。

### G.3 Real PostgreSQL restart

```text
active Tactical Combat
→ movement paused on OA
→ restart app
→ reconnect
→ same board / positions / pending reaction
→ resolve
→ continue exactly once
```

不得以 in-memory / SQLite 作唯一證據。

### G.4 Concurrent stale command

至少模擬 Human 與 AI 同時 Confirm 同一 subject movement、DM correction 與 Player 舊 movement 競爭、map runtime revision 變更與舊 AoE confirm 競爭。只允許一個合法 state transition，另一方拿 stable stale/conflict error。

### G.5 Real ChatGPT Web Tactical gate

使用既有正式 M04 connector，不建測試專用入口。最低流程：

```text
AI get_session_context
→ read Tactical context
→ preview/commit movement
→ use formal attack or spell
→ handle or observe spatial reaction
→ wait_for_event
→ continue after another Human action
→ reconnect/refresh continuity
```

驗收者必須在 AT UI 看到實際 position / turn / roll / HP / reaction 等 state 變化。失敗時保存實際 tool error / server evidence；不能只用 AI 自述。

### G.6 Secrecy matrix

對 DM / Human Player / AI Player 檢查 hidden token、hidden door、既有 enemy secrets、runtime secret ids、movement interruption error、AoE preview、event / Resume / REST / MCP。任何 Player-visible path 洩漏都視為 blocker。

### G.7 Standalone

重跑 M03 import boundary / schema parity。若 P5 diff 觸及 shared packaging/import boundary，再依 `AGENTS.md` 要求升級到對應 standalone build / smoke gate。P5 Web schema 不得出現在 Standalone SQLite。

### G.8 Closeout evidence

P5 closeout 至少記錄 backend focused + full relevant regression、frontend unit + build、migration/PostgreSQL tests且無 silent skip、P5 browser E2E、Quick regression E2E、full-stack workflow run id、real ChatGPT Web Tactical gate日期/role/journey、secrecy matrix、standalone boundary、static review findings與處理結果。

## 4. 人工驗收重點

人眼確認：地圖可以很快開、不像大型地圖製作軟體；Token 拖曳自然但 Confirm 前不會偷偷 commit；5/10 preview 容易理解；range / AoE feedback 足夠；Cover 保留 DM 裁定、不出現假的 LOS 精準感；OA pause 不會讓流程卡死；hidden 敵人不因 path preview 明顯洩密；Quick 沒被 Tactical UI / data requirements 污染；AI 可從 structured context理解地圖，而不是靠 host 口述整張 map。

---

## 5. P5 closeout blocker

以下任一成立不得關 P5：

- Quick Combat 需要 Battle Map 或 coordinates 才能運作。
- Tactical 有第二套 attack / spell / damage / reaction business logic。
- client / MCP 可直接改 canonical position。
- Map Definition 與 Combat runtime 互相污染。
- preview / commit 使用不同 distance / AoE 演算法。
- hidden spatial data 從任一 Player-visible surface 外洩。
- movement / OA retry 可重複消耗或重複位移。
- pending OA 在 restart / reconnect 後消失。
- forced movement 錯誤觸發 generic OA。
- Tactical Combat 仍依 DM 手動判普通 range，而沒有使用 spatial truth。
- Human 與 AI 走不同 spatial validation。
- P5 multiplayer schema 污染 Standalone。
- 真實 ChatGPT Web Tactical journey 未通過。
