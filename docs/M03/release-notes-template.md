# Adventure Table Standalone

Adventure Table standalone Character Builder for Windows x64.

> **M03 compatibility notice:** Character JSON schema is **unstable** during M03. JSON exported by this release is not guaranteed to import into a future release until the schema is locked at P2.

Extract the ZIP before launching `adventure-table.exe`.

The bundled `README-standalone.zh-TW.txt` and `README-standalone.en.txt` explain:

- where the local SQLite database is stored;
- how to import and export characters;
- how to stop the standalone server;
- the current Windows-only and multiplayer limitations.
