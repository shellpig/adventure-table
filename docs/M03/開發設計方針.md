## 1. 設計目標

- **一份 codebase，兩個 entry point**：`app.main`（線上版）與 `app.standalone`（單機版）共用 `app.content` / `app.domain` / `app.persistence` / `app.api`；差別只在掛哪些 router、指向哪個資料庫、`GET /api/meta/capabilities` 回什麼值。`app.standalone` **不 import** `app.main`；共用邏輯放在 neutral module。
- **匯入／匯出 server-authoritative**：build_payload、state_payload 與 refs 收集邏輯只住 server，前端不重建。匯入必經 domain validators。
- **content 與 data 位置抽象化**：`REPOSITORY_ROOT` 等常數全部改為呼叫 resolver；`api/dependencies.py` 對 `CONTENT_PACKS_ROOT` 的 import 一併遷移。
- **Enabled pack 為可注入 setting**：測試不靠刪目錄模擬缺 pack。
- **Alembic 一條鏈**：Postgres 與 SQLite 走同一條 migration 鏈，SQLite 由 CI gate + FK PRAGMA hook 保證。
- **Standalone 相依可裁**：`psycopg` 移到 optional extra，PyInstaller 不打包網頁 driver。
- **P2 界線機械化**：character domain 對 room / session / seat / campaign 的隔離由 static import graph test 強制；`app.standalone` 不 import `app.main`。
- **資料根位置單一化**：release 產物採 `<exe_dir>/data` 與 `<exe_dir>/web`；PyInstaller bundle 不內嵌第二份。

## 3. Path 解析（M03-A 主題）

### 3.1 新增 `apps/server/app/paths.py`

```python
from pathlib import Path
import os
import sys


def _executable_dir() -> Path | None:
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent
    return None


def _meipass_root() -> Path | None:
    meipass = getattr(sys, "_MEIPASS", None)
    return Path(meipass) if meipass else None


def resolve_content_root() -> Path:
    env = os.environ.get("ADVENTURE_TABLE_CONTENT_ROOT")
    if env:
        candidate = Path(env)
        if candidate.is_dir():
            return candidate
        raise RuntimeError(
            f"ADVENTURE_TABLE_CONTENT_ROOT 指向的路徑不存在: {candidate}"
        )

    exe_dir = _executable_dir()
    if exe_dir is not None:
        candidate = exe_dir / "data"
        if candidate.is_dir():
            return candidate
        meipass = _meipass_root()
        if meipass is not None:
            fallback = meipass / "data"
            if fallback.is_dir():
                return fallback
        raise RuntimeError(
            f"frozen 模式找不到 data 目錄: {candidate}（也未於 _MEIPASS 找到）"
        )

    # dev / test：repo 相對
    # 檔案位於 apps/server/app/paths.py
    # parents[0]=app, [1]=apps/server, [2]=apps, [3]=repo root
    return Path(__file__).resolve().parents[3] / "data"


def resolve_rules_path() -> Path:
    return resolve_content_root() / "rules" / "dnd5e-2014" / "character-builder.json"


def resolve_localization_root() -> Path:
    return resolve_content_root() / "localization"


def resolve_srd_content_root() -> Path:
    return resolve_content_root() / "srd5.1"


def resolve_spa_root() -> Path | None:
    """Standalone 用：<exe_dir>/web；非 frozen 時可能為 None。"""
    exe_dir = _executable_dir()
    if exe_dir is not None:
        candidate = exe_dir / "web"
        if candidate.is_dir():
            return candidate
    env = os.environ.get("ADVENTURE_TABLE_SPA_ROOT")
    if env:
        candidate = Path(env)
        if candidate.is_dir():
            return candidate
    return None
```

實作者於 M03-A 開工時以檔案實際位置驗證 `parents[3]` 深度，若 apps 結構調整則同步修正。

## 4. JSON schema（M03-B 主題）

### 4.1 Pydantic model

`app/interop/json_schema.py`：

```python
class Envelope(BaseModel):
    schema_version: Literal["unstable"]              # P2 lock 後改為 "1.0.0" 等
    schema_status: Literal["unstable", "locked"]
    ruleset: str                                     # e.g. "dnd5e-2014"
    content_requirements: list[PackRequirement]
    stable_key_refs_summary: int
    source_character_id: UUID
    source_export_id: UUID
    source_app: SourceApp
    exported_at: datetime


class PackRequirement(BaseModel):
    pack: str                                        # e.g. "srd5.1"
    version: str                                     # pack manifest version at export time


class SourceApp(BaseModel):
    name: Literal["adventure-table"]
    channel: Literal["web", "standalone"]
    commit: str | None
    build: str | None


class ExportedVersion(BaseModel):
    version_no: int
    version_kind: str
    parent_version_no: int | None
    superseded_by_version_no: int | None
    change_note: str | None
    build_payload: dict[str, Any]
    builder_provenance: dict[str, Any] | None
    created_at: datetime


class ExportedCharacter(BaseModel):
    name: str
    ruleset: str


class ExportedState(BaseModel):
    state_payload: dict[str, Any]


class ExportPayload(BaseModel):
    character: ExportedCharacter
    current_version_no: int
    versions: list[ExportedVersion]
    current_state: ExportedState


class CharacterExport(BaseModel):
    envelope: Envelope
    payload: ExportPayload
```

Note：`build_payload` 與 `builder_provenance` 於 schema 上仍以 `dict[str, Any]` 呈現，實際型別驗證由 domain layer（`CharacterBuild.model_validate`）於 import pipeline 中執行。

### 4.2 `content_requirements` 計算

- 由 `content_ref_walker.collect_build_refs()` 走訪每個 `versions[*].build_payload`，`collect_state_refs()` 走訪 `current_state.state_payload`。
- 每個 ref 帶 pack 名稱（來自 StableKey 前綴）；集合完成後查匯出當下 registry 取得該 pack 的 manifest version。
- **匯出當下 registry 中該 pack 的 version** 寫入 requirement，不追溯歷史。這是預期行為：`content_requirements` 只是診斷用，真實 gate 靠匯入端解析 StableKey。

### 4.3 `stable_key_refs_summary`

- 整數：`len(build_refs_union_over_all_versions) + len(state_refs)`。
- 純診斷用；匯入端不依賴此數字。

### 4.4 匯出檔命名

- `{sanitized_character_name}-v{current_version_no}-{exported_at_utc}.json`
- Sanitized：允許 `[A-Za-z0-9_\-\.]`，其他字元換 `_`；截斷至 60 字元；empty 時 fallback `character`。

### 4.5 Endpoint

```
GET /api/characters/{character_id}/export
  → 200 OK application/json
       Content-Disposition: attachment; filename="..."
       X-Adventure-Table-Character-Archived: "true" | "false"
  → 404 character_not_found
```

### 4.6 `builder_provenance` 欄位

Alembic migration（`<next>_m03b_builder_provenance.py`）：

- `add_column("character_versions", "builder_provenance", JSON().with_variant(JSONB(), "postgresql"), nullable=True)`

## 5. Import pipeline（M03-C 主題）

### 5.1 API contract

```
POST /api/characters/import
  Content-Type: application/json
  Query:
    dry_run: bool = false

  Body:
    { envelope: {...}, payload: {...} }

  → 200 OK ImportResult (dry_run=true)
  → 201 Created ImportResult (dry_run=false, success)
  → 400 import_rejected + reason code
```

**只接受 JSON body**：不引入 `python-multipart`。前端檔案選擇於瀏覽器端 `File.text()` 讀出後以 JSON body POST。

`ImportResult`：

```python
class UnresolvedRef(BaseModel):
    stable_key: str
    kind: str
    pack: str
    index: str
    origin: Literal["build", "state"]
    version_no: int | None            # build ref 帶所在 version；state ref 為 None

class ImportPreview(BaseModel):
    name: str
    ruleset: str
    highest_level: int
    class_summary: list[str]
    version_count: int
    current_version_no: int

class DuplicateHint(BaseModel):
    prior_import_count: int
    most_recent_imported_at: datetime

class ImportResult(BaseModel):
    landing_mode: Literal["character", "draft"]
    resolved_count: int
    unresolved_refs: list[UnresolvedRef]
    character_preview: ImportPreview
    duplicate_hint: DuplicateHint | None
    committed: bool
    landed_character_id: UUID | None
    landed_draft_id: UUID | None
    source_export_id: UUID
```

### 5.2 Rejection codes

以 M02-G / M02-H 建立的 machine-readable + params 契約為模板：

- `invalid_envelope_shape`
- `invalid_payload_shape`
- `unsupported_schema_status`
- `unsupported_ruleset`
- `version_chain_gap`
- `version_chain_out_of_order`
- `current_state_version_missing`
- `version_lineage_invalid`
- `invalid_build_shape`
- `state_shape_invalid`
- `build_references_invalid`
- `state_inconsistent_with_build`
- `draft_reconstruction_unavailable`

前端把 code + params 翻成 `zh-TW` / `en` presentation，比照 M02-H builder issue 契約。

### 5.3 Content ref walker

`app/interop/content_ref_walker.py`：

- `collect_build_refs(build_payload: dict) -> Iterable[ContentRef]`。
- `collect_state_refs(state_payload: dict) -> Iterable[ContentRef]`。
- `ContentRef` = `{stable_key: str, kind: str, pack: str, index: str}`。
- 走訪策略：
  - 依 build_payload / state_payload 目前 schema，明列所有帶 StableKey 的路徑。**避免用 reflection / 全 dict 遞迴猜**；若某個 pack 資料形狀變動，要用 test 抓，而不是靠 walker 沉默漏收。
  - Build refs 涵蓋範圍（M01 Full Closeout 後預期）：race / subrace / lineage / background / class / subclass / features (choices + granted) / spells (known / prepared / spellbook / always-prepared source) / feats / infusions / maneuvers / fighting styles / starting equipment refs / tool / language / skill proficiency identity（若走 StableKey）/ numeric override targets（若走 identity）。
  - State refs 至少涵蓋：
    - `CharacterState.conditions[].condition_ref`
    - `CharacterState.prepared_spells[].spell_key`
    - `CharacterState.inventory_state`（`InventoryEntry.item_ref`）
    - `CharacterState.active_infusions[].infusion_ref`
    - `CharacterState.spell_storing_item.spell_ref`
    - 其他 M01 期間可能引入的 stable-key ref（如新增 slot resource identity 等）
- Walker 本身純函式，不呼叫 registry；registry 由呼叫端傳入或另做 resolver 呼叫。
- Walker 對無法辨識的 dict shape 應 fail-fast（例：raise `UnknownRefShape`）；不容許沉默漏收。

### 5.5 Commit — `landing_mode == "character"`

```python
def commit_import_as_character(
    payload: CharacterExport,
    session: DBSession,
) -> UUID:
    with session.begin():
        new_character_id = uuid4()
        insert characters (id, name, ruleset, current_version_id=NULL)
        # 先建立 version_no → 新 UUID 對照
        version_id_by_no = {v.version_no: uuid4() for v in payload.versions}
        for v in payload.versions:
            insert character_versions(
                id=version_id_by_no[v.version_no],
                character_id=new_character_id,
                version_no=v.version_no,
                build_payload=v.build_payload,
                version_kind=v.version_kind,
                parent_version_id=version_id_by_no.get(v.parent_version_no),
                superseded_by_version_id=version_id_by_no.get(v.superseded_by_version_no),
                change_note=v.change_note,
                builder_provenance=v.builder_provenance,
                created_at=v.created_at,
            )
        current_version_id = version_id_by_no[payload.current_version_no]
        update characters.current_version_id = current_version_id
        insert character_states(
            character_id=new_character_id,
            state_payload=payload.current_state.state_payload,
        )
        insert character_import_records(
            id=uuid4(),
            character_id=new_character_id,
            draft_id=NULL,
            source_character_id=envelope.source_character_id,
            source_export_id=envelope.source_export_id,
            landing_mode="character",
            imported_at=now,
        )
    return new_character_id
```

**Preview 已跑完的 domain validators 於 commit 開始時再跑一次**（防禦 dry-run 與 commit 之間 registry 狀態變動）。

### 5.6 Commit — `landing_mode == "draft"`

- 從 `payload.versions[current_version_no].builder_provenance` 建立 fresh CREATE Draft，走既有 `builder_drafts` 模組的 create flow。
- 建立時，把 provenance 中對應「未解析 ref」的 selection 欄位清空為未填。
- 完成之後把 `source_character_id` / `source_export_id` 記入 `character_import_records`，`landing_mode="draft"`，`draft_id=<new draft id>`。
- **Current state 不進 Draft**：Draft 沒有 live state 的概念，Confirm 產生 Version 1 時走一般 initial state 建立流程。
- Legacy character（`builder_provenance` 為 `None` 於 current version）於 preview 階段已被 reject，不進 commit。

### 5.7 Import records table

Alembic migration `<next revision>_m03c_character_import_records.py`：

```
character_import_records
  id                    UUID PK
  character_id          UUID NULL   FK → characters.id ON DELETE SET NULL
  draft_id              UUID NULL   FK → character_build_drafts.id ON DELETE SET NULL
  source_character_id   UUID NOT NULL
  source_export_id      UUID NOT NULL
  landing_mode          VARCHAR(16) NOT NULL
  imported_at           TIMESTAMPTZ NOT NULL DEFAULT now()
  INDEX (source_character_id)
  INDEX (source_export_id)
```

- `character_id` / `draft_id` 二選一 nullable：character 落地時 draft_id NULL，反之亦然。
- 記錄不刪；即使原 character 被 permanent delete，`source_character_id` 仍留作 dedupe 提示。
- **SQLite 上 FK 語意由 M03-D 建立的 `PRAGMA foreign_keys=ON` hook 保證**。

### 5.8 Duplicate hint

```python
def find_duplicate_hint(
    imports_repo: ImportRecordsRepo,
    source_character_id: UUID,
) -> DuplicateHint | None:
    records = imports_repo.list_by_source(source_character_id)
    if not records:
        return None
    return DuplicateHint(
        prior_import_count=len(records),
        most_recent_imported_at=max(r.imported_at for r in records),
    )
```

## 7. Alembic on SQLite（M03-D 主題）

### 7.1 現況掃描

M03-D 開工第一件事：把現有全部 migration（0001 至當時 head，含 M03-B、M03-C 新增者）逐一在 SQLite 上跑一次 upgrade → downgrade → upgrade，抓出：

- `postgresql.JSONB` 直接引用（不透過 `with_variant`）。
- 未包成 `batch_op` 的 `alter_column` / `drop_constraint` / `add_constraint`。
- `server_default` 使用 Postgres-only function（`gen_random_uuid()` 等）。
- 使用 Postgres-only 型別（`ARRAY`、`INET`、`CIDR` 等）。

### 7.2 修法

- 有問題的 migration 就地修（M03-D 允許改 migration 檔內容），保持 Postgres 上的既有行為不變。
- 修法優先順序：
  1. `sa.JSON().with_variant(postgresql.JSONB(), "postgresql")` 已是 pattern，全面採用。
  2. `alter_column` 一律包 `batch_op`。
  3. `server_default` 用 dialect-neutral（例：`sa.text("...")` 分 dialect）。
- 若某 migration 真的無法 SQLite-friendly（例：以 Postgres partial index 表達的 unique），視情況於 SQLite dialect 分支跳過，並於 migration comment 明列。

### 7.3 SQLite FK PRAGMA event listener

於 `app/db.py` 建 engine 時掛 hook：

```python
from sqlalchemy import event
from sqlalchemy.engine import Engine


@event.listens_for(Engine, "connect")
def _enable_sqlite_fk(dbapi_connection, connection_record):
    # 只對 SQLite dialect 生效
    if type(dbapi_connection).__module__.startswith("sqlite3") or \
       type(dbapi_connection).__module__.startswith("pysqlite"):
        cursor = dbapi_connection.cursor()
        cursor.execute("PRAGMA foreign_keys=ON")
        cursor.close()
```

- Hook 全域註冊一次；適用於 web、standalone、pytest、launcher 於 alembic upgrade 時的 engine。
- 若 hook 位置與其他 event listener 衝突，實作者調整放置位置，維持全域生效即可。

```python
from pydantic import BaseModel

meta_router = APIRouter(prefix="/api/meta", tags=["meta"])


class Capabilities(BaseModel):

def build_capabilities(channel: Literal["web", "standalone"]) -> Capabilities:
```

### 8.2 `app/standalone.py`

```python
from fastapi import FastAPI
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles

from app.api import (
    character_builder_router,
    characters_router,
    content_presentation_router,
    reference_router,
)
from app.api.error_handlers import register_exception_handlers
from app.api.meta import mount_meta_router
from app.config import settings
from app.content import load_default_content_registry
from app.paths import resolve_spa_root


def create_standalone_app() -> FastAPI:
    content_registry = load_default_content_registry()
    app = FastAPI(title=f"{settings.app_name} (standalone)")
    app.state.content_registry = content_registry

    app.include_router(reference_router)
    app.include_router(content_presentation_router)
    app.include_router(characters_router)
    app.include_router(character_builder_router)
    mount_meta_router(app, channel="standalone")

    register_exception_handlers(app)

    spa_root = resolve_spa_root()
    if spa_root is not None:
        # 資源檔（css/js/asset）走 StaticFiles，SPA history fallback 走 catch-all
        app.mount("/assets", StaticFiles(directory=spa_root / "assets"), name="assets")

        @app.get("/{full_path:path}", include_in_schema=False)
        def spa_fallback(full_path: str) -> FileResponse:
            candidate = spa_root / full_path
            if candidate.is_file():
                return FileResponse(candidate)
            return FileResponse(spa_root / "index.html")

    return app


app = create_standalone_app()
```

**關鍵**：
- 不 import `app.main`。
- 不呼叫 alembic upgrade（由 launcher 執行）。
- SPA 位置由 `resolve_spa_root()` 決定，優先 `<exe_dir>/web`。
- Catch-all SPA fallback 保證 `/characters/<uuid>` 直接 reload 也能載到 `index.html`。

### 8.4 `app/launcher.py`

```python
def main() -> int:
    setup_paths()                              # 決定 content_root、spa_root、data path
    port = find_free_port(range(8000, 8100))
    run_migrations(sqlite_url_from(env))       # alembic upgrade head
    print_banner(
        port=port,
        sqlite_path=...,
        content_root=...,
        spa_root=...,
    )
    server = start_uvicorn(app_module="app.standalone:app", port=port)
    wait_ready(port)
    open_browser(f"http://127.0.0.1:{port}/")
```

細節：

- `wait_for_shutdown`：signal handler（SIGINT / CTRL_CLOSE_EVENT on Windows）。**不**做「瀏覽器關分頁自動停 server」，避免新增 shutdown/heartbeat 契約。

## 13. 錯誤處理與觀察

### 13.1 Import endpoint

- 拒絕時回應體：`{"error": {"code": "<rejection_code>", "message": "...", "params": {...}}}`；比照 M02-H 已建立的 machine + params 結構。

### 13.2 Launcher

- Alembic upgrade 失敗：印錯誤 → 保留 console → 不自動關閉，讓使用者截圖回報。
- Port 全部被佔：印可讀訊息並中止。
- Content root / SPA root 找不到：印解析出的絕對路徑並中止。

### 13.3 Server startup（standalone）

- Content pack 若少於 `settings.enabled_content_packs`（例：`srd5.1` 缺失）→ 中止並印訊息。這通常代表 `<exe_dir>/data` 沒放好。
