# M07-D — Full M07 Integration & Closeout

## D.1 整合旅程

真 PG 與隔離 assets：舊資料 migration → 場外兩庫 → 內建複製成自訂 → map 預放／改模板 → Session Start → 僅 map 與 map＋怪物兩種開戰 → 最新數值且 hidden 保密 → Party placement／initiative → Attack／Move／Reveal／Reaction → Session End 保留 Combat → 下一場接續 → End Combat 後 Player history → 第二 Campaign 重用庫 → 封存與引用安全 → restart。

另驗 Quick、空庫／空圖、零 Adventure、optional Scene 均合法。既有 P5 延期 AI gate 與 legacy 施法限制按已知問題列明；M07 新回歸不可沿用延期理由放行。

## D.2 正式 AI 驗收與 P7 交接

透過 M04 正式 HTTPS connector 與 Join Kit，AI DM 在 active Session：查兩庫 → 讀自訂模板 → 庫圖帶配置開戰 → DM 可見 hidden／Player 不可見 → Reveal → End Combat → 臨時地圖開新戰鬥 → 證明庫沒有新增圖 → 寫庫／舊工具被拒 → revoke 後讀取被拒。AI Player 使用實際 scope 驗戰場保密，不拿 DM response 偽裝 Player。保存去除憑證的 tool request／response、UI 觀察與 Server 證據。

P7 文件在 M07-D 修訂：Room 模板、配置／封存／revision、typed references、引用閉包、import remap；Snapshot 不回捲 Room authoring、Instance 快照保持。三份 P7 契約一致、Character JSON v1 不變；不在 M07 實作 P7 或提前跑不存在的匯出功能。

## D.3 關門 gate

- 全套 backend pytest、frontend unit／build、Compose config、全套 Docker E2E，沿 AGENTS。
- 真 PG Alembic migration（舊 heads → 新 heads）、restart、資料隔離與 race，不以 SQLite create_all 替代。
- Standalone forbidden naming／protected seeds／schema parity、Web↔Standalone Character exchange；若 Python 相依或 packaging 改動，依 constraints 與 frozen build／smoke gate。
- 新頁面兩 locale、規則呈現、首次 expose 的描述與 searchable 欄位同步；fallback 不冒充完成。
- 驗收 ID → 實際 test node／spec／commit／環境／結果；正式 AI、人工操作手感證據。
- 文件與產品規格一致、P7 交接、KI-P5A-001 修復證據及已知問題處置、簡報狀態／關門後移歷史。
