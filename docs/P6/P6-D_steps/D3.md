# D3 — Stage bridge：asset／entry image → P3 Stage

## Scope

- `set_stage_image(actor, source)`：source 為 Room asset id、Adventure entry asset 或 Runtime entry image；application boundary 經 Room／asset authority（`RoomAssetService.open_content`）讀 bytes，**複製一份**成既有 `room_stage_images`，再沿用 `ExplorationStageService.replace_stage` 的 revision／event／notifier 語意。
- `session_stages.image_id` 仍只指向 stage image；不公開 asset URL／storage key；dm_only asset 只有 DM 能當來源，Player 只讀合法 stage image。
- 不遷移 `room_stage_images` schema，不改 `ExplorationStageService` contract。
- 一條 Session DM REST route（依既有 `/api/rooms/{room}/...` convention）供 D5 UI 使用。

## 契約與輸入

- 設計 D.3；測試 D.5。前置：D0b（與 D1／D2 獨立）。

## 驗收

- `tests/test_p6d_stage_bridge.py`：bytes 複製後 stage image 與來源 asset 獨立（刪 asset 不影響 stage）；`image_id` 指向 stage image；Player 讀 stage 拿不到 asset id／storage key；非 DM／非本場 actor／revoked 拒絕零副作用；route 測試沿 P6-B API 模式。
