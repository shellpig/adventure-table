# C1 — CampaignContextService：campaign／scene context 與單筆 entry read

## Scope

- 新增 `app/domain/campaign_runtime/context.py`（或同 convention 命名）`CampaignContextService`，輸入 `TableActorContext`（active Session），輸出 role-projected structured DTO：
  - `get_campaign_context(actor)`：Campaign identity／summary、Current Scene label＋Current Situation、current Party（participants＋active Character 摘要）、Active Combat compact ref（有時）、attached Adventure refs（DM only）、Runtime entry refs（依 audience projection）。
  - `get_scene_context(actor, scene_ref?)`：解析 Adventure scene ref／Runtime scene ref／預設 Current Scene；DM 回 baseline＋override 合併且 current truth 明確優先；Player 只回 Runtime public／own-character。
  - `get_world_entry(actor, world_entry_id)`：轉交 `CampaignRuntimeService.get_active`。
  - `get_adventure_entry(actor, adventure_entry_id)`：DM only；轉交 `get_adventure_entry_overlay_active`；Player／AI Player 一律 authority error，不得回 not-found 之外的存在提示。
- 不做 search（C2）、不碰 `get_session_context`／MCP（C3）、不做 write-back。

## 契約與輸入

- 規格 P6-C 全段；設計 Architecture、Shared authority / projection、C.1 Context service（不含 search）；測試 C.2、C.4、C.5 的 service 層部分。
- 依賴 P6-B 已有：`CampaignRuntimeService` active read intents、`project_runtime_aggregate`、`CampaignAdventureEntryOverlayView`、`CampaignRuntimeContext`；`CombatLifecycleService.get_active_combat`；session participants。

## 驗收

- `tests/test_p6c_context_service.py`：DM／AI DM parity；Human Player／AI Player projection（無 Adventure entry id／title／body／source ref、無 dm_only／dm_notes、無他人 character）；override 存在時 baseline＋current 都在且 current 標示優先；scene ref 三種來源＋無 Current Scene；空 Campaign；stale／revoked actor、inactive Session 拒絕。
- 測試用 parametrize／shared fixture，同一矩陣不展開成獨立 function。
