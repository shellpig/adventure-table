# C2 — search_campaign_context：bounded、deterministic、零 side channel

## Scope

- `CampaignContextService.search_campaign_context(actor, query, kinds?, limit?)`：PostgreSQL normalized text／simple indexed matching（SQLite 相容 fallback 供單元測試），deterministic 排序、limit＋pagination、max payload；空字串／全空白 query 拒絕。
- DM：Runtime truth／Override > attached Adventure baseline，結果標示來源與 override 狀態。
- Player／AI Player：只搜 Runtime public＋own-character knowledge；不得因命中 Adventure entry 或 secret 而回傳 id／title／body／source ref／命中數／存在提示。
- 若需要 index／migration，走 `0033`，含真 PostgreSQL upgrade／downgrade test。
