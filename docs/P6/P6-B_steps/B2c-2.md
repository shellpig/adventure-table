# B2c-2 — Active Session actor、world event／notifier 原子接線

## Scope

- 將 active Session `TableActorContext` 接入 B2c-1 共用 Runtime mutation；只允許每次重驗仍 current 的 Human/AI DM 寫入，Player／stale grant/controller 拒絕。
- 使用既有 TableEvent transaction projection 擴充點，在同一 transaction 原子寫 target row＋campaign mutation＋安全 `world.*` event；失敗零半筆。
- event payload 只含安全識別／revision／kind，不帶 dm_notes、secret body、character recipient 或完整 state；成功後 notifier 一次。
- active actor read使用 B2a projection：DM全部；Player public＋own controlled Character knowledge。

## 契約與輸入

- 依賴 B2c-1；P6 Shared authority、Events、Concurrency/idempotency；沿用 P3-D `TableActorContext`／current binding。

## 驗收

- Human/AI current DM parity；Player/非 participant/stale actor拒絕；public/own/other/dm-only projection；retry不重複 world row/event；revision conflict與 callback失敗 rollback target/mutation/event；notifier success only。
