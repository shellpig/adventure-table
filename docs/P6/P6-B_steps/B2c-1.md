# B2c-1 — Mutation repository、Session 外管理 CRUD／projection

## Scope

- 實作 `campaign_world_mutations` connection-aware repository，保存 campaign-scoped command/result identity，duplicate key 僅在 command identity 相同時 replay；不同 command collision 拒絕。
- 建立 Campaign Runtime service 的共用 mapper／projection與 Human Room owner/dm Session 外 create/update/archive/get/list。
- 每筆管理 mutation 在單一 transaction 內完成 campaign/room authority scope、target row、recipients、mutation record；不建立 fake Session event／notifier。
- update 將既有 kind、state、visibility/recipients 與 patch 合併後重跑 B2a invariant；Player/Member 不可管理寫入。

## 契約與輸入

- 依賴 B2a/B2b；P6 Shared authority、B.1/B.4、Concurrency/idempotency、Events。

## 驗收

- owner/dm success；member/wrong Room/Campaign拒絕零副作用；create/update/archive retry replay；same key different command拒絕；revision conflict不留 mutation record。
- management read為 DM view；pure projection list/get另覆蓋 public/own/other/dm-only matrix供 B2c-2/B4重用。
