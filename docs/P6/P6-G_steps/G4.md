# G4 — 真實 ChatGPT Web connector world-state journey

## Scope

- 指揮者使用既有 M04 正式 connector 與真實 ChatGPT Web AI DM，跑 `get_session_context`／相關 P6 context、敘事／正式 Check／Quick Combat、Campaign Fact／Runtime write-back、`wait_for_event`、重連／next Session。
- 在 AT UI／資料庫核對外部 AI 的實際 write 與後續 context；模型文字自述不算證據。
- 不新增網站 LLM client、API key 或 AI-specific authority bypass。

## 契約與驗收

- 規格 P6-G G.2；測試指南 G.4。記錄 connector 授權、tool result、AT state／revision 與 reconnect 證據；Player／stale grant 拒絕仍有效。

## 測試方法（AI 自主主持）

- 開場只給 ChatGPT 一句「你是這桌的 AI DM，開始主持」類的指示；**不給工具名稱、entry id、關鍵字或劇情提示**，後續也不逐步指定要呼叫哪個工具。
- Human 只扮演 Player（在 Player UI 行動／擲骰）；指揮者只查 DB／event／UI，不代替 AI 做決定。
- AI 靠 briefing／guide／context 自己想不出下一步時，視為產品缺陷：修程式與契約，不以改寫提示詞補救。逐步口述指令得到的結果不算 G4 證據。
