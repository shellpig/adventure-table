# G1b-1 — Empty Campaign：Quick Combat attack／damage／End

## Scope

- 延續 G1a 的同一 `p6g-empty-campaign.spec.ts` journey，在已解的 Player roll 後進入 Quick Combat；DM 使用現有 P4 流程加入敵人／完成 initiative、Player 或 DM 合法完成一次 attack 與 damage，然後 End Combat。
- 斷言 Combat entry、attack resolution、HP／Character Current State 的實際 AT state；Player 不操作 DM 專屬裁定，隱藏敵人資源不洩漏。
- 本步保持零 Adventure、零 Tactical geometry；Current Situation 與 next Session 留 G1b-2。擴充後 spec 可單獨通過。

## 契約與驗收

- 規格 P6-G G.1；測試指南 G.1 Quick Combat 段、G.6。參考 `e2e/p4e-quick-combat.spec.ts`、`p4f-full-combat-journey.spec.ts` 與 `support/quickCombat.ts`，核對最新 helper／route／DTO。
- 新 spec Docker E2E、相關 P4 regression、frontend unit／build、code quality gate 通過。不改 production combat 以迎合測試；若發現 A～F 真缺口，回報來源。
