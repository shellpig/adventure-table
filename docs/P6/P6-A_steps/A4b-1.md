# A4b-1 — web：Adventure editor（definition＋entries）

## Scope

- `apps/web/src/features/rooms/AdventureEditorPage.tsx`：`AdventureEditorPage({ roomId, adventureId })`，由 `RoomAdventuresPage` 在 `adventureId` 存在且通過 `missingAccess`／`noAuthority` guard 後 render（取代 A4a placeholder；移除 `detailAdventure` state 與 `editorPlaceholder` copy）。
- Definition：name／summary 編輯（`patchAdventure`）、status 顯示、finalize／archive 按鈕沿用 `adventureActions`＋既有 client；`archived` 全部唯讀（無表單、無 mutation 按鈕）。
- Entries：`listAdventureEntries` 依回傳順序（server 已按 `sort_order`）顯示；`parent_entry_id` 非 null 者縮排；新增 entry：選 kind → 通用 title／body／visibility／parent（僅可選 `section` entry）＋該 kind 最小欄位；編輯（同表單，`patchAdventureEntry`）、刪除（`window.confirm`）、上／下移（交換相鄰位置後送 **全部 entry id** 給 `reorderAdventureEntries`）。
- Kind 欄位對照 server `payloads.py`：`scene` read_aloud／dm_summary；`npc` role／disposition；`item` rarity／value_gp／is_magic；`monster_ref` monster_template_ref（必填）／count；`quest` objective（必填）／reward；`secret` reveal_condition；`suggested_check` ability／skill／dc（必填）；`map` caption；`lore` topic；`section`／`dm_note`／`other` 無額外欄位。
- `adventuresCopy.ts` 追加 editor copy 兩 locale。
- Vitest：`AdventureEditorPage.test.tsx`（pure helper：payload 組裝、reorder 順序、kind 欄位表；`renderToStaticMarkup` 驗 entries 列表與 archived 唯讀；copy parity；source 斷言 delete 走 confirm）。
- 不做 entry 圖片（A4b-2）。

實作規格 P6-A「Adventure entry 至少可表達…」「finalized Adventure 仍可由 Room owner / dm 做 authoring 修正」「Human UI…可建立、瀏覽、編輯」；設計 §A.2（typed payload、visibility 只是 authoring semantics）、§A.3、「REST / UI surface ▸ Adventure editor」。
