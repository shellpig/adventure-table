# F2 — Finalize transaction：blocking gate、draft → Adventure Definition／entries、`target_adventure_id` idempotency

## Scope

- `AdventureImportService.finalize_adventure(context, room_id, import_id, *, name, summary=None, expected_revision) -> AdventureDefinition`，單一 transaction：
  1. 讀 import（同 Room、非 cancelled）；**若 `target_adventure_id` 已設，直接回該 Adventure，不重建、不改 revision**（拍板決策 2：`target_adventure_id` 即 idempotency 鍵，F.4 的 double submit／retry／reconnect 由此滿足）；
  2. revision guard（`expected_revision` 不符 → `AdventureImportRevisionConflictError`，零副作用）；
  3. `unresolved_blocking_warnings` 非空 → `AdventureImportValidationError`（可由呼叫端映射 409），零副作用；
  4. 建 `AdventureDefinition`（status `draft`）與 entries：`review_status == "ignored"` 的 entry **不建**，其餘全建（不要求逐條 accept）；draft 的字串 `entry_id` → 新建 entry UUID 的對應表用於 `parent_entry_id`；`sort_order` 依 draft entries 順序；`asset_ids` 逐一呼叫既有 `link_entry_asset`；
  5. 呼叫既有 `AdventureService.finalize` 讓 Adventure 進 `finalized`；
  6. 把 import 標 `finalized` 並寫入 `target_adventure_id`（revision-guarded）。
- 失敗任一步整筆 rollback：不留半套 Adventure、不改 import status。
- `AdventureImportService` 建構子接受 `AdventureService`（或其所需 repository）；**不複製 P6-A 的 authoring 邏輯**，一律委派既有 public API。
- finalize 後的 Adventure 是 authoring baseline：gameplay／Runtime／AI world write 不得改寫（P6-B／P6-D 既有行為不動）；Room owner／dm 仍可用既有 P6-A authoring route 修正。
- 不做 route（F3）、MCP（F4）、UI（F5）。

## 驗收

- `tests/test_p6f_finalize.py`（parametrize）：
  - happy path：draft 的 entries 轉成 Adventure entries，parent／sort_order／payload／visibility 與 draft 一致；`ignored` entry 不出現；`asset_ids` 產生 entry asset link；import status `finalized` 且 `target_adventure_id` 指向新 Adventure（F.4）。
  - idempotency：同一 import 連續兩次 finalize（含不同 `expected_revision`）只產生一個 Adventure，第二次回同一 id、不新增 entries、不重複 link（F.4）。
  - blocking gate：未解 blocking → 拒絕且無 Adventure／無 status 變更；解掉後可 finalize（F.1）。
  - 全部 entry 停在 `pending` 也能 finalize；只處理 warnings 也能完成（F.3）。
  - rollback：在 entry 建立中途強制失敗（例如非法 payload／不存在的 asset id）→ 無 Adventure row、無 entries、import 仍非 finalized、revision 不變。
  - authority：MEMBER／跨 Room 拒絕零副作用；cancelled import 拒絕。
