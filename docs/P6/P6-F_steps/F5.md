# F5 — UI：Draft Review 面板、Finalize、zh-TW／en、E2E

## Scope

- Importer 區擴充 Review 能力（DM-only，沿既有 `canAuthor` gate）：
  - 每個 draft entry：Accept／Edit／Ignore／Mark uncertain 動作與目前 `review_status` 顯示；View source（跳到該 entry `source_ref` 對應 source 的 chunk 位置，沒有 source_ref 時不顯示）；
  - Warnings 分區依 Info／Warning／Blocking 顯示，Blocking 未解時 Finalize 停用並說明原因；warning 可 resolve；question 可作答；
  - Finalize 表單（Adventure name／summary）與成功後導向既有 Adventure editor；重複送出不產生第二個 Adventure（依 F2b idempotency）。
  - **不要求逐條 Accept**：UI 不得把 Accept 做成 finalize 前置條件。
- 開工前先決定是否拆 `AdventureImporterPanel.tsx`（P6-E closeout 觀察 1：1,241 行）。建議拆成 Source 區與 Draft／Review 區兩個元件再加功能；拆與不拆都要在本檔說明理由。
- locale：所有新 copy、review status／warning level／finalize 錯誤文案 zh-TW／en parity。
- E2E `apps/web/e2e/p6f-import-review.spec.ts`：DM 建 import → 貼文字 → 建 draft entry → 製造一個 blocking warning → Finalize 被擋 → resolve → Finalize 成功 → Adventures 列表出現新 Adventure → 重整後 import 顯示 finalized 且指向同一 Adventure；Player 看不到 Review／Finalize 控制。
