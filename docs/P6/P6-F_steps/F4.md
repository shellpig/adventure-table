# F4 — 六個 Importer MCP tool＋catalog／guide parity＋authority

## Scope

- `app/mcp/tools.py` 新增六個 `MCPToolDefinition`（薄 facade，沿 P6-D D4 模式：只做 input 驗證與 intent 轉發，不自行 parse 內容）：
  `import_adventure_source`、`get_import_draft`、`update_import_draft`、`resolve_import_warning`、`answer_import_question`、`finalize_adventure`。
- Authority（拍板決策 3）：`roles=frozenset({"dm"})`、`pre_session=False`——**只有 active Session 的 current AI DM 可用**；AI Player、stale／revoked grant、controller_epoch 過期、非 active Session 一律拒絕且零副作用。沿用既有 `require_active_table_actor` 取得 canonical actor，再橋接成 importer service 需要的 Room authority（**不得偽造 `RoomAccessContext` 繞過 Room／Seat／grant**，也不得放寬 pre-session grant 的工具集合）。
- Tool input 直接組合既有 domain model／既有 service 參數，不新增第二套 schema；`import_adventure_source` 對應 E2／E3 的 `add_text_source`／`add_url_source`／`add_asset_source`，以 discriminated input 區分 source kind。
- `update_import_draft` 沿用 `expected_revision`（required），其餘 mutation tool 同樣 required。
- Tool description 雙語並進既有 M04 catalog／guide parity（`_WHEN_TO_USE`、`guide_tool_names.py`、`test_m04c_*`）。
- 不做 UI（F5）；不改 Player 工具集；不改 pre-session briefing cap。
