# F3 — REST：review／resolve／answer／finalize route

## Scope

- `app/api/rooms/adventure_imports.py` 新增（沿既有 router、authority 與 `_map_*_error` 模式）：
  - `POST /adventure-imports/{import_id}/draft/entries/{entry_id}/review`（body：`review_status`、`expected_revision`）；
  - `POST /adventure-imports/{import_id}/warnings/{warning_id}/resolve`（body：`resolution`、`expected_revision`）；
  - `POST /adventure-imports/{import_id}/questions/{question_id}/answer`（body：`answer`、`expected_revision`）；
  - `POST /adventure-imports/{import_id}/finalize`（body：`name`、`summary?`、`expected_revision`），回新的 `AdventureDefinition`。
- error mapping：stale revision → 409；未解 blocking → 409 並帶可辨識 machine code（例如 `import_blocking_warnings`）；不存在 id → 404；MEMBER／跨 Room → 既有 403／404 convention。錯誤訊息 zh-TW／en 沿既有 room error 機制。
- 前端 client（`apps/web/src/api/adventureImports.ts`）補四個函式與型別，供 F5；input／response shape 分離，沿 E4 既有寫法。
- 不做 MCP（F4）、不做 UI 元件（F5）。
