# E4 — REST `/api/rooms/{room}/adventure-imports/...`（DM-only）

## Scope

- 新增 `app/api/rooms/adventure_imports.py`，掛進 rooms router：
  - `POST /adventure-imports`、`GET /adventure-imports`、`GET /adventure-imports/{import_id}`、`POST /adventure-imports/{import_id}/cancel`；
  - `POST /adventure-imports/{import_id}/sources`：raw-body upload（沿 `room_assets.py` 的 upload 模式；`source_kind`、`filename`、`url` 走 query／header）與 JSON body（paste／url with text）兩種入口；`POST .../sources/from-asset`；
  - `GET .../sources/{source_id}/chunk?offset=&limit=`；
  - `GET .../draft`、`PUT .../draft`（body 含 `expected_revision`）。
- error mapping 沿 `_map_room_asset_error` 模式；stale revision → 409；Player／非成員 → 403／404 依既有 room convention。
- 前端 client：`apps/web/src/features/rooms` 既有 api 模組新增對應函式與型別（供 E5）。
