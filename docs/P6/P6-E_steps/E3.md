# E3 — PDF／DOCX extractor＋從 room asset 建 source

## Scope

- 新增 `app/domain/adventure_imports/extractors.py`：`pypdf`（PDF）與 `python-docx`（DOCX）deterministic text extraction，**函式內 lazy import**；輸出 normalized text 與 locator（PDF：page index／DOCX：paragraph／heading index）寫入 `metadata_json.sections`；無可抽文字 → source warning `empty_extraction`，不做 OCR、不假裝成功；套件缺失 → 明確 `ExtractorUnavailableError` 映射為 source warning。
- `AdventureImportService.add_source` 支援 `pdf`／`docx` kind 與 `asset_id` 來源（讀 P6-A room asset bytes，asset 必須屬同 Room 且 media type 相符）。
- `pyproject.toml`：兩套件只加 `[project.optional-dependencies].web`，**不進 base `dependencies`、不進 standalone**。
- 靜態檢查：importer package 無 model API client／API key setting／外部 LLM HTTP call。
