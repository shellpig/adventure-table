# E2 — `AdventureImportService`：paste／txt／markdown／url source、chunk 讀取、Draft revision

## Scope

- 新增 `app/domain/adventure_imports/service.py` `AdventureImportService`（`RoomAccessContext`，Room owner／dm only；Player 拒絕零副作用）：
  - `create_import(room, name)`、`list_imports`、`get_import`、`cancel_import`；
  - `add_source(import_id, source_kind, *, text | bytes, filename?, url?, media_type?)`：`paste`／`txt`／`markdown` decode（UTF-8，BOM 容錯）＋normalize（換行、trailing whitespace）、`sha256`、`metadata_json`（filename、media_type、byte size、line count）；同 import 重送相同 sha256 回同一 source row（idempotent）；`url` kind 只存 `source_url` + 呼叫端提供的 normalized text／excerpt metadata，**backend 不 fetch**；URL 無 content 時建立 source 並掛 source warning，status 停 `source`；
  - `read_source_chunk(import_id, source_id, *, offset, limit)` bounded 讀取（limit 上限由 Settings 固定），回 `total_length`、`next_offset`；
  - `get_draft`、`update_draft(import_id, draft, expected_revision)`：stale 拒絕零副作用；首次 update 由 `source` 轉 `drafting`。
- 不做 PDF／DOCX（E3）、不做 route（E4）。

## 契約與輸入

- 規格 P6-E；設計 E.1、E.2（TXT／Markdown、URL 段）；測試 E.1、E.3、E.4。前置：E1。
- 參考檔：`app/domain/adventures/service.py`（RoomAccessContext authority 模式）、`app/domain/room_assets/service.py`（size limit／Settings）。

## 驗收
