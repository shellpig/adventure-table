# M02 — 測試指南

> Phase：**M02 — Traditional Chinese / English Localization**  
> 類型：**M Phase（Modification / Maintenance Phase）**  
> 插入時點：**M01-C — SCAG / GoS Background Expansion closeout 後，暫停 M01；M02 closeout 後回到 M01-D。**  
> 本文件定義 M02-A～M02-H 的自動化與人工驗收流程。完成條件以 `實作規格.md` 為準，具體接線與資料模型以 `開發設計方針.md` 為準。

最後更新：2026-08-30

---

## 1. 測試總則

M02 的測試不能只驗「畫面上有中文」；必須同時驗：

1. 語言切換的 runtime 行為正確。
2. locale 不污染 Draft / Character / Current State。
3. UI copy 與 rules content 都能完整切換。
4. StableKey / persisted identity 不因語言改變。
5. user-authored text 不被翻譯。
6. search / sort / error presentation 使用目前 locale。
7. 缺翻譯會被自動化 gate 擋住。
8. M02 closeout 時 `srd5.1 / phb2014 / scag / gos` 具有完整雙語 coverage。

所有 Subphase 完成時都必須保持既有 backend pytest、frontend build / Vitest、Playwright 與 relevant regression 綠燈。

## 2. 共通測試資料與觀察值

### 2.1 Locale

正式測試 locale：

```text
zh-TW
en
```

### 2.2 必須觀察的不變 identity

切換 locale 前後至少比較：

- current URL
- Builder Draft id
- Draft revision
- selected StableKeys
- Character id
- current version id / version number
- CharacterBuild refs
- CharacterState values

### 2.3 必須觀察的 presentation

至少涵蓋：

- UI heading / button / label
- SearchableSelect options
- Builder grants / choices
- class / race / background / spell / equipment names
- rule description
- validation / error message
- roleplay system suggestion
- source label（若有）

# M02-A — Locale Foundation & Runtime Switch

## A.1 Unit / component tests

驗證：

- default locale 為 `zh-TW`。
- browser storage 有 `en` 時初始化為 `en`。
- invalid stored locale 不被接受，回到合法 default。
- 切換 locale 更新 runtime state。
- 切換後 browser storage 正確保存。
- `html lang` 同步。

## A.2 No mutation test

在有既存 Builder Draft 的頁面：

1. 讀取 Draft revision。
2. 切換 `zh-TW → en → zh-TW`。
3. 再次讀取 Draft。

必須：

- revision 完全相同。
- draft payload 完全相同。
- 不發生 PATCH / Confirm / Cancel mutation。

可用 frontend request spy 或 real backend request log 驗證。

## A.3 Browser persistence E2E

1. 開啟網站，切 English。
2. reload。
3. 仍為 English。
4. 離開頁面再重新開啟。
5. 仍為 English。
6. 切回繁中，reload。
7. 仍為繁中。

## A.4 No reload E2E

在 Character Builder 中輸入尚未失焦 / 尚未 mutation 的 local UI state（若 component 有），切換 locale。

必須：

- page 不 reload。
- current step 不變。
- focus / relevant transient state 不因 navigation 消失。

# M02-B — Full UI Copy Localization

## B.1 Static UI coverage

建立可維護的 UI copy inventory 或等價檢查，至少涵蓋：

- Landing
- Workshop
- Builder steps 01～06
- Character Sheet
- Version History
- shared components

每個 surface 在 `zh-TW` / `en` 都有對應 copy。

## B.2 Hardcoded visible text regression

對 frontend source 做 targeted lint / test / review，避免新增明顯 user-visible hardcoded English / Chinese literal。

不是要求禁止任何 string literal；測試應只針對 presentation surface，避免誤傷 enum、code、StableKey、test fixture。

## B.3 Accessibility

兩種 locale 都驗：

- aria-label
- accessible button name
- form label
- placeholder / hint（若是可見或 accessibility-relevant）

語言切換後 accessible name 同步更新。

## B.4 Mixed-language smoke

在純繁中與純英文模式巡覽主要頁面，記錄任何可避免的 system UI 混語；Blocker / Major 必須在 B closeout 前清掉。

# M02-C — Localized Content Model & Terminology Contract

## C.1 StableKey invariant

使用同一 content entry，例如：

```text
srd5.1:spell:fireball
```

分別 resolve `zh-TW` / `en`。

驗證：

- identity 相同。
- canonical mechanics data 相同。
- 只有 presentation fields 不同。

## C.2 Resolver fixture

至少用數種不同 kind 測試：

- race / background
- proficiency / skill
- equipment
- spell
- feature
- long description

每種都能正確取得兩語 presentation。

## C.3 Missing translation behavior

故意建立缺一個 locale / field 的測試 fixture：

- development resolver 可明確指出 missing translation。
- completeness test 必須 fail。
- 不得 silent fallback 後仍通過 completeness。

## C.4 DTO identity test

Builder / Character rules presentation path 中，驗證 rules item 有足夠 StableKey / structured identity 支援 locale switch。

禁止只有 raw English `label` 而無法追溯 identity 的 user-visible rules entity 成為新的 contract。

## C.5 Roleplay suggestion identity

測試 system-provided suggestion：

1. 同一 suggestion 在 English 顯示英文。
2. 切繁中後顯示繁中。
3. persisted selection / identity 不因 locale 改變。

另測 user manually typed roleplay text：

- 切 locale 後原文不變。

## C.6 Glossary review gate

建立 glossary consistency fixture / review checklist，至少抽查核心術語在不同 content kinds 不會出現多套未定義翻法。

## D.1 Dataset coverage

至少覆蓋：

- abilities
- alignments
- backgrounds
- classes
- conditions
- damage-types
- equipment-categories
- equipment
- feats
- features
- languages
- items
- magic-schools
- proficiencies
- races
- skills
- spells
- subclasses
- subraces
- traits

## D.2 Builder option presentation

以 real Builder choices 抽查：

- Race
- Subrace
- Background
- Alignment
- Class
- proficiency / language choices
- equipment choices
- spells

切 locale 後 option display 全部更新，selected persisted value 仍是同一 StableKey。

## D.3 Character Sheet presentation

建立含多種 SRD refs 的 Character，驗：

- class / race / background
- proficiencies
- features
- equipment
- spells
- conditions

兩語 render 正確。

## D.4 No identity drift

比較兩語下 Review / Confirm candidate：

- Build refs 相同。
- content_sources 相同。
- mechanics result 相同。

# M02-E — SRD 5.1 Full Descriptions

## E.1 Long-text completeness

對所有被 localizable field policy 標成 user-visible long text 的 SRD entry 執行 coverage scan。

缺任一 locale 即 fail。

## E.2 Rules fidelity spot check

至少抽查：

- 低等 spell
- 高等 spell
- concentration spell
- condition
- feat
- class feature
- racial trait
- magic item
- weapon property

比較翻譯前後：

- dice expression
- numeric values
- level
- range / duration
- condition / limitation
- named rules references

不得因翻譯遺失或改變。

## E.3 Structured rendering

若 description 有 list / paragraph 結構，兩種 locale 都需：

- 不破版。
- 不把 list 黏成難讀單行。
- 不因 locale 切換遺失內容。

# M02-F — PHB / SCAG / GoS Localization

## F.1 Pack completeness

對：

```text
phb2014
scag
gos
```

執行完整 user-visible localizable field coverage。

每個 pack 都必須 `zh-TW` / `en` 全綠。

## F.2 PHB flow

至少一條完整 E2E：

```text
PHB race/subrace or Variant Human
+ PHB background
+ SRD class
```

在 Builder 中：

- 繁中顯示完整繁中 rules presentation。
- 切 English 後完整英文。
- selection / Draft 不變。
- Confirm 後 Character Sheet 兩語都正確。

## F.3 SCAG background flow

至少一個會 reuse PHB roleplay suggestion table 的 SCAG Background：

- roleplay suggestions 兩語正確。
- mechanical grants 仍是 SCAG background 自己的 grants。
- locale 不影響 roleplay inheritance isolation。

## F.4 GoS flavor flow

至少一個帶 optional flavor table / suggestion 的 GoS Background：

- 兩語可見。
- 留白不阻擋 Confirm。
- 選用 system suggestion 後 identity 可跨 locale render。

## F.5 Variant / source collision

同名或近似名稱跨來源同時存在時：

- 兩語 source-aware display 都能辨識。
- persisted key 永遠是正確完整 StableKey。
- locale switch 不發生誤選或 dedupe。

# M02-G — Localized Search, Errors & Completeness Gates

## G.1 Localized search

繁中模式：

- 中文名稱可搜尋。
- English alias 也可命中。
- 結果只顯示繁中 presentation。

English mode 反向驗證。

## G.2 Locale-aware sort

準備一組名稱排序會與 StableKey/index 順序不同的 fixture，驗證：

- `zh-TW` 依繁中 display presentation 排序。
- `en` 依英文 display presentation 排序。

## G.3 Validation errors

觸發至少：

- missing required choice
- illegal choice
- stale / invalid state
- generic request error

驗證：

- machine code / path 不變。
- UI message 隨 locale 切換。
- 動態 rules name 也隨 locale。

## G.4 Completeness CI

CI 必須自動掃描 M02 closeout packs：

```text
srd5.1
phb2014
scag
gos
```

任何 required field 缺：

```text
pack
StableKey
field
locale
```

即測試失敗，並輸出可定位資訊。

## G.5 Future content guard

加入一個新測試 fixture / fake entry，只有 English 沒有繁中時，確認 guard 失敗；補齊後才通過。

此測試用來證明 M02 closeout 後 M01-D 起不會再無聲加入單語 content。

# M02-H — Full M02 Integration & Closeout

## H.1 Full regression

至少包含：

- backend pytest
- localization dataset validation
- fresh migration / existing schema compatibility（若 M02 有 migration）
- frontend TypeScript build
- Vitest
- real-backend Playwright
- restart / reload relevant persistence

## H.2 Full bilingual Create Character E2E

至少完成兩條：

### Flow 1 — 繁中開始

```text
zh-TW
→ Create Draft
→ Origin
→ Abilities
→ Class
→ Spellcasting（若 caster）
→ Equipment
→ Review
→ Confirm
→ Character Sheet
→ switch en
→ verify same Character / Build / State, English presentation
→ reload
```

### Flow 2 — English 開始

反向完成一條 create flow，再切 `zh-TW` 驗證。

## H.3 Draft safety stress

建立有多個 selection 的 Draft：

- race
- subrace
- background
- class progression
- spell choices
- equipment choices
- roleplay user text

連續多次切：

```text
zh-TW → en → zh-TW → en
```

驗證：

- Draft revision 不因純切語言增加。
- payload 不變。
- selected StableKeys 不變。
- user text 不變。

## H.4 Character State safety

在 Character Sheet 先建立可觀察 live state：

- HP damage
- Temp HP
- condition
- resource used
- prepared spell
- inventory state

切換 locale 多次並 reload。

所有 live state 不變。

## H.5 Pure-language human browser gate

人工逐頁巡覽：

- Landing
- Workshop
- Builder every step
- Review
- Character Sheet every relevant tab/section
- Version History

分別以 `zh-TW` / `en` 進行。

Blocker：

- 主要 rules name / description 顯示錯語言。
- 切語言造成 Draft / Character state mutation。
- reload 才能完成切換。
- locale persistence 失效。

Major：

- 可達頁面出現明顯 system/rules 混語。
- error / empty / loading / accessibility copy 漏翻。
- search result / source label 錯語言。

Blocker / Major 必須在 M02 closeout 前清零。

## H.6 Completeness final gate

最終 gate 必須證明：

```text
srd5.1  zh-TW ✓  en ✓
phb2014 zh-TW ✓  en ✓
scag    zh-TW ✓  en ✓
gos     zh-TW ✓  en ✓
```

且所有目前既有 user-visible localizable fields 無已知缺漏。

## H.7 Resume gate

M02 closeout 後，才可 resume：

```text
M01-D — VGM Race Expansion
```

從 M01-D 起，每個新增 user-visible system / rules content 的測試都必須同時驗 `zh-TW` / `en` coverage；缺任一 locale 視為該 Subphase regression failure。
